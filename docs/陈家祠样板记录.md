## 1. 入口

```text
http://127.0.0.1:4188/spot.html?id=chenjiaci
```

机位参数：

```text
&preset=overview   总览（默认）
&preset=front      正立面
&preset=detail     屋脊细节
&preset=courtyard  庭院
&preset=alley      青云巷
&debug=1           后台也持续渲染（仅用于测试）
```

图鉴入口：

- 打开 `http://127.0.0.1:4188/`
- 点「陈家祠」→ 详情面板底部「进入模型」

> 如果 4188 端口还是旧进程，先重启 `npm run dev`；新版预览服务需要把 `/content/` 暴露出来，否则模型页读不到数据卡和模型模块。

## 3. 已验证

### 页面与模型

- 页面加载完成，无控制台错误。
- 模型可拖动旋转、滚轮/双指缩放、方向键微调、双击复位。
- 五个机位可切换：总览、正面、细节、庭院、青云巷。
- 3 个热点（屋脊陶塑、木雕屏门、青云巷）可打开信息卡；“拉近看”可切到对应机位。
- 移动端 390×844 可打开；面板默认收起，工具栏「详情」可展开。

### 图鉴联动

- 图鉴详情按钮显示「进入模型」。
- iframe 打开 `spot.html?id=chenjiaci`，加载成功。
- 「标记去过」写入 `canton-atlas-marks`，并同步到图鉴：徽标变为「✓ 去过」，计数 +1。
- iframe 内「返回图鉴」通过 `postMessage` 关闭覆盖层。

### 性能样本

- `__SPOT_API__.bench(90)`：**1.9 ms/frame**（桌面软件渲染测试）。
- 350 draw calls / 10,054 triangles。
- 阴影贴图只在第一帧生成，后续不重复渲染。

> 350 calls 超出规范里 <100 的优化目标，但当前帧时间很低；视觉优先，后续再合并/实例化。
