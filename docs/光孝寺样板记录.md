## 1. 光孝寺的记忆点

- **岭南第一古刹**：广州历史最悠久的寺院建筑，广州四大丛林之首；
- **大雄宝殿**：东晋始建，保留唐宋建筑风格；重檐歇山；
- **瘗发塔**：唐仪凤元年（676），为六祖惠能剃度埋发而建；八角七层仿楼阁式砖塔；
- **菩提树**：南朝梁天监元年（502）智药三藏从印度带来；中国有记载的第一棵菩提树；现存树高约 16m、冠幅约 18m；
- **东西铁塔**：南汉铸造，七层；
- **六祖惠能**：在寺中落发、受戒，光孝寺因此成为禅宗祖庭。

来源：广州市政府、越秀区政府（A），广州日报菩提树（B）。

---

## 2. 模型范围

- 模型是 **120×90m 中轴段 diorama**，不是整座寺院 1:1。
- 包含：山门、天王殿、大雄宝殿（重檐）、瘗发塔、六祖殿、菩提树、东西铁塔、钟鼓楼、东西廊庑、香炉。
- 不含：寺院全部院落、僧舍、内部展陈、真实法会。
- 单位：1 unit = 1m；Y 向上；北 = -Z。
- **注意**：瘗发塔在模型里移到东侧院落，以保证从总览/塔机位可见；这是展示性处理，不是现场测绘。
