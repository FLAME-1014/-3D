# 文化带片区浏览（2026-11-02）

## 功能
- 探索面板增加“珠江新城文化带”：文化带总览与开始手动探索。
- 总览按三地标锚点范围和屏幕宽高比计算镜头；窄屏适度拉远，保证体量范围进入视野。不是精确地籍或道路范围。
- 手动顺序为省博→图书馆→大剧院，可通过站点选择直接跳转；下一站只在点击后执行，最后一站显示完成探索，不循环、不自动播放。
- 退出/完成保留当前镜头和自由浏览；区域或片区总览退出探索并隐藏近景模型，沿用15秒资源回收。
- 详情分“了解建筑”与“附近去哪儿”，模型等级在当前地点栏和详情标题区保留。切到周边才触发POI激活；若维持周边分区，换地标时查询随当前可见模型更新。
- 未绘制路线、步行距离、导航引导；明确镜头探索不是步行导航。

## 测试与修正
- 新增三项自动测试：站点合法与结束边界、宽窄屏拟合、Three相机投影下各地标示意范围进入视锥。
- 浏览器验证文化带总览、1/3→2/3→3/3、完成后探索栏消失、自选图书馆、退出保留当前地点、详情分区及高德图书馆6条结果。
- 发现窄屏详情层遮挡下一站，改为使用实际探索栏高度计算详情位置；390×844实测探索栏 top567/bottom724，详情 bottom553，页脚top742，无重叠、无横向溢出。
- 844×390横屏复测退出后左右详情分离、页脚避让；站点select排除全局地图键盘快捷键，避免选择操作触发WASD。
- 完成/退出后焦点回探索入口，不留在隐藏按钮。视口改变时重新拟合片区总览。
- 本轮只检查浏览器布局和交互；真机双指、软键盘、安全区及持续性能待验收。模型仍是既有两细模加图书馆体量样板。
