# 省博同图融合样板 · 2026-11-02

入口：http://127.0.0.1:4188/immersive/fusion.html（npm run dev）

## 验证目的

单一 Three.js scene/camera/canvas 内，从轻量城市总览靠近省博，按距离切换简模和建筑细模。不是 iframe 切页，不修改原图鉴和城市总览路由。

## 范围与实现

- 新建轻量示意底座：珠江、道路、简化广州塔、批量建筑体量；不是原城市POC的整体迁入，也不是准确地理地图。
- 复用省博模型，新增显式 assetOnly 导出，仅返回主体外壳/屋面/底层，不带旧场景地面、树木和压缩城市。
- 首次靠近加载省博纹理和模型脚本；距离小于470触发细模、大于620返回简模，避免边界反复切换。
- 细模拉远后隐藏并缓存，不代表释放GPU内存；大规模多地标需要另外设计资源卸载。
- 城市总览/靠近省博/俯看屋面按钮，拖拽、滚轮、双指和键盘控制；减少动态效果偏好下镜头立即切换。
- 地点介绍侧栏；POI、导航、夜景和全广州配准不在本轮范围。

## 已检查

- 39个JS语法、66个本地资源引用检查通过；本地服务测试通过。
- 浏览器点击靠近：细模和侧栏出现，单canvas，无iframe，无错误日志。
- 拉远返回：简模恢复，侧栏关闭，无横向溢出。
- 原省博独立页仍可加载、完成开场隐藏，错误日志为空；非完整七视点回归。
- 桌面前台HUD样本：总览25 calls/2,886 tris；细模31 calls/17,290 tris；屋面约32 calls/17,302 tris。前台观察曾读60fps，后台标签节流会降帧，不能当正式性能验收。
- 移动CSS已提供，但尚未完成手机视觉/触控验收。
