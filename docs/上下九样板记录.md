# 上下九样板记录 · 2026-11-03

> 目标：按 **B 级** 做上下九 · 骑楼街的街段 diorama，验证“连续骑楼 + 老字号茶楼 + 霓虹”的商业街表达。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 为什么是上下九

上下九不是“又一条骑楼街”，而是：

- **连续骑楼**：上九路—下九路—第十甫路连绵千米，2–4 层，南欧建筑与西关传统结合，连廊遮阳挡雨；
- **老字号**：陶陶居（1880，第十甫路 20 号）、莲香楼（1889，“莲蓉第一家”）、广州酒家、皇上皇；
- **步行街牌坊**：1995 年 9 月 30 日开街，中国第一条商业步行街；
- **霓虹招牌**：傍晚亮灯后的西关商业界面；
- **陶陶居屋顶六角亭**：米白骑楼、薄荷绿横梁、金色灰塑，屋顶琉璃瓦六角亭是整条街最有辨识度的轮廓。

来源：广州市商务局（A）、人民网（A）、维基百科（C）。

## 2. 和北京路的区别

| | 北京路 | 上下九 |
|---|---|---|
| 核心 | 千年古道 + 大佛寺 | 连续骑楼 + 老字号茶楼 |
| 街宽 | 16m | 约 15m |
| 记忆点 | 脚下的 11 层古道 | 头顶的骑楼连廊 + 陶陶居屋顶亭 |
| 招牌 | 骑楼/书店/大佛寺 | 陶陶居/莲香楼/广州酒家/皇上皇 + 霓虹 |

两个模型都用“博物馆展柜”语言，但上下九把重心放在**骑楼连廊和老字号**，不再做古道/寺庙。

## 3. 模型范围

- 模型是 **120×70m 街段 diorama**，压缩了约 **1237m** 的上下九步行街。
- 包含：120m 连续骑楼（两侧各 8 个街块）、连续券廊/雨棚/柱列、陶陶居（薄荷绿横梁 + 屋顶六角亭）、莲香楼、广州酒家、皇上皇、步行街牌坊、老字号霓虹、满洲窗、麻石街、长凳。
- 不含：华林寺、玉器街内部、整条 1237m、店铺内部。
- 单位：1 unit = 1m；Y 向上；北 = -Z。

- 陶陶居屋顶六角亭用简化亭子表示，未做内部/琉璃瓦细部。
- 骑楼柱距、街宽、建筑高度为示意；真实测绘未做。
- 满洲窗是程序化纹理，不是逐窗复原。
- 老字号只保留陶陶居/莲香楼/广州酒家/皇上皇等代表，店铺内容不逐一建模。
- 霓虹是静态发光板，不做动画/真实灯管。
