# 永庆坊样板记录 · 2026-11-02

> 目标：按 **B 级** 验证同一“博物馆展柜”风格能否从院落（陈家祠）转到街道（永庆坊）。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 入口

```text
http://127.0.0.1:4188/spot.html?id=yongqingfang
```


## 2. 范围与口径

- 模型是 **96×70m 街段 diorama**，不是整个 11.37 万㎡ 永庆坊。
- 主街约 84m，两侧为 3–4 层骑楼；含主巷、李小龙祖居、街面广福台。
- 单位：1 unit = 1m；Y 向上；北 = -Z。
- 图鉴内容复用 `data.js`；模型数据卡在 `content/spots/yongqingfang/spot.json`。

来源：

- 荔湾区政府《永庆坊》：11.37 万㎡、一期 2016、麻石街/微改造（A，已核）。
- 广东省情网《永庆坊》：11.37 万㎡、83 处历史建筑、26 项非遗、4A（A，已核）。
- 项目考据 `qoder-docs/.../2026-10-31-yongqingfang-facts.md`（B）。
- 旧城市 POC 坐标 GCJ-02 `[113.2461, 23.1155]` → WGS84 `[113.240777, 23.118186]`（C，未与 OSM/测绘核对）。

## 3. 已实现

- 连续骑楼廊道：柱廊、顶棚、梁、底层店面、上层满洲窗。
- 永庆坊门楼：砖墙、门洞、木门、瓦顶、铜色“永庆坊”匾、灯笼。
- 主巷与李小龙祖居：巷口门架、西关大屋、木门/满洲窗、匾。
- 街面广福台：红柱、舞台、瓦顶、“广福台”匾、灯笼。
- 5 个机位：总览 / 街道 / 门楼 / 广福台 / 细节；机位通过 `presetOverrides` 按景点覆盖。
- 图鉴 iframe、打卡、返回、移动端 390×844 已验证。

## 4. 实测

- 300 draw calls / 8,856 triangles。
- `__SPOT_API__.bench(90)`：**1.48 ms/frame**（桌面软件渲染测试）。
- 页面无控制台错误。
- 图鉴联动：点「永庆坊」→「进入模型」→ iframe 加载 → 「标记去过」写 localStorage / 图鉴计数 +1 → 「返回图鉴」关闭。

**B 级通过标准**：来源 + 风格 + 性能 + 交互 + 识别 lite。  
`silhouette / proportion / scale` 是 A 级严格项；B 级记 `null`，不记 `false`；每 5 个 B 级景点抽 1 个做 A 级 5 人。
