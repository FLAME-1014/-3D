# 双地标接入 · 2026-11-02

## 实现

同一fusion入口接入省博/大剧院，原独立页面保留。大剧院precinctOnly导出双砾、玻璃口部、浅层大厅、平台、栏杆、水池、草坡；在旧场景大地面/道路/城市创建前返回。不是完整广场和树阵复原，模型朝向/中心与锚点仍为近似。

地标分别管理加载Promise、细模、纹理、可见状态和15秒卸载定时器。当前选择地标在靠近时加载，非选择地标回简模，避免两个邻近地标同时触发。入口/屋面视角跟随当前地标。侧栏仅在地标切换时更新，不每帧重写。

POI查询中心/缓存按地标隔离，类别缓存键为地标+分类，请求序号防止晚返回污染当前列表。高德坐标仍不进入WGS84场景。Shader动画时间同步，释放时包含uniform纹理引用。
