# 三地标接入与注册规范（2026-11-02）

## 范围与资料可信度
广州图书馆接入同图探索，但目前是**体量样板，不是精细复原**。现有历史考据 `qoder-docs/superpowers/research/2026-10-31-huacheng-facts.md` §2.5 记录北楼10层/南楼8层、“美丽书籍”概念与区域锚点；引用含百科/项目介绍转述，竞赛年份也有不同口径，本轮未将这些转述升级为新核实事实。
- 区域坐标沿用既有 WGS84 近似锚点 `[113.32059,23.11885]`；不是测绘轮廓。
- 样板北楼50m/南楼40m、宽约105m、南北跨度约86m、朝向、水平层带、连接中庭和入口均为估计，不应作为实际尺寸或外观验收依据。
- 没有加入独立城市、整片地面或另一个近景页面。原省博、大剧院独立场景未改。
- 图书馆外形精度下一步需官方项目图/可用参考照片与平面资料确认后迭代，不用本样板代替这一步。

## 新地标接入约定
`web/immersive/fusion-catalog.js` 统一定义：
1. 唯一 id / 名称 / 英文 / 别名 / 区域 / 分类 / 模型等级。
2. anchor 指向 `fusion-geo.js` 的明确 WGS84 锚点；不得把高德 GCJ-02 值写入此处。
3. labelPriority、views（相对锚点 offset、radius、theta、phi）。
4. model.script/global；textureScript/textureGlobal 可选。模型 build 返回 `{root}`，可选动画 uniforms；每次构建资源独立，以便完整释放。
5. coarseBoxes 为新地标低细节盒体参数（w,h,d,x,y,z）；既有两地标保留原简模适配。标记按钮、搜索结果、详情、POI 与近景模型加载均从注册资料驱动。
6. size/height/content/note 明确标注事实与推测边界。
7. poi.name/radius 用高德地点搜索单独确定查询中心，保持坐标系统隔离。

## 生命周期与缓存修正
- 当前选择按距离显示模型，离开或返回总览即隐藏，15秒后释放几何、材质和纹理。
- 未展示的预加载模型也设释放计时，避免快速切换或中断镜头留下永久缓存。
- 失败加载回退并设5秒重试间隔，避免每帧重试。
- 修正高德缓存实际写入/读取使用分类键的问题：统一按 `地标id:分类`，仍保留序列守卫防止旧请求覆盖新地标。
- HUD 新增 WebGL geometry/texture 数量。这不是总内存字节、JS 堆或泄漏证明；需持续切换压测。

## 验证记录
- 三个注册条目完整性、广图别名、推荐视角通过测试。
- 图书馆共享单盒体几何、18个实例化层带、局部边界、独立构建资源通过测试。旧版 Three 实例化边界不会自动覆盖全部实例，层带关闭视锥剔除，防止靠近时误消失。
