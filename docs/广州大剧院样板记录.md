## 1. 广州大剧院的记忆点

- **双砾石**：一黑一白、一大一小两块“被珠江水冲刷的砾石”，Zaha Hadid Architects 设计，2010-05-09 启幕；大砾石在西/深灰近黑，小砾石在东/白或浅灰。两体最近约 3 m（课程分析口径，未测绘）。
- **没有直角的折面**：三向斜交折板式单层网壳，屋顶与幕墙连续；大砾石公开结构分析口径 64 个空间折面 / 104 条棱线 / 41 个空间角点，小砾石 37 / 54 / 18。不是两个光滑椭球。
- **大玻璃口部**：大砾石南/东南的大三角玻璃“口部”是主入口形象，内部钢斜网格清晰；小砾石南/东是较低较长的玻璃带。
- **三角形石材 + 点支玻璃**：外立面约 5,000+ 块三角玻璃、约 75,000 块三角石材（精确口径 5,200 / 75,422）；大砾石深色石材、小砾石白色石材。公开资料未确认铝板为主表皮。
- **5 m 平台 + 水池 + 草坡**：南入口沿缓坡上到 5 m 标高入口平台，平台是大小砾石共用的室外门厅；建筑置于水池之中，草坡是“山丘”的组成部分。
- **方位**：花城广场西南角、珠江西路 1 号；东接广东省博物馆/广州图书馆，南望珠江/海心沙/广州塔，北靠广州国际金融中心（西塔）。模型对周边只做压缩示意。

来源：Zaha Hadid Architects 项目页（A）、广州大剧院官网（A）、公开结构分析/课程资料（B）、百度百科（B）、照明公开资料（B）、OSM（未核）。详细条目见 `canton-atlas/content/spots/opera-house/spot.json`。

## 2. 模型范围

- 模型是 **220×220 m 场地段 diorama**，不是 42,000 ㎡ 全用地 1:1，也不是剧场内部。
- 包含：大砾石（西、深色）约 120×85×43.1 m 的无直角三角折面体量；小砾石（东、浅色）约 65×45×28 m（估算）；约 3 m 间距（示意）；大砾石南/东南三角玻璃口部 + 内部斜网格 + 暗色大堂背板与暖光带；小砾石南/东低长玻璃带；5 m 入口平台、边缘暗缝/水纹光带、支撑柱；南侧缓坡；水池（主池 + 东支池）；草坡/山丘、树阵、灯柱、铺装与“广州大剧院”小字牌；北/东侧省博、图书馆、西塔为低对比压缩剪影。
- 布局约定：大砾石中心约 `(-34, -38)`，小砾石约 `(55, -15)`；西 = `-X`，东 = `+X`；南 = `+Z`，北 = `-Z`；地面 `y=0`，入口平台顶 `y=5`；原点在底面中心。
- 不含：剧场/舞台/后台/观众厅/排练厅/餐厅内部、地下车库与落客区、室内导览、RGB 灯光秀、每日灯光节目、逐块玻璃/石材、真实镜面倒影。

## 8. 已知取舍 / 待改

- 双砾折面是低模折面壳：用环状三角网格 + 平面法线 + 板缝线表达“无直角/三角分片”，不逐面复刻 64/104/41 或 37/54/18；近看比真实折面更规整。
- 大玻璃口部是简化的大面玻璃 + 斜向钢网格；内部只做暗色大堂背板与暖光带，不做观众厅/舞台/座位；玻璃后不是真实室内。
- 小砾石高度约 28 m、平面约 65×45 m、双砾约 3 m 间距、水池/草坡/坡道尺寸均为估算/示意；不写测绘值。
- 水池是透明高光材质 + 深色池底，不做真实镜面倒影；夜景“水映双砾”只保留轻微平台水纹光带，默认日光展柜，不声称实时灯光/RGB。
- 三角形石材/玻璃分片用程序化纹理 + 实际三角折面 + 板缝线表达，不逐块建 5,000+ 玻璃/75,000 石材；石材风化/雨痕很轻。
- 入口门位、平台边缘狭缝、坡道宽度为示意；草坡下的咖啡/售票/研究空间、地下车库、落客区不做。
- 北/东侧省博、图书馆、西塔只做低对比压缩剪影，不抢双砾；广州塔/珠江/海心沙不入模，避免遮挡与误导。
- 大砾石“黑色”在强日光下会呈深灰；这是展柜灯光与材质取舍，不声称现场色号。铝板未作为主表皮。
- 移动端总览为装下 220 m 场地，`spotId === "opera-house"` 使用局部距离倍率上限 2.0（其他 spot 仍 1.8）；同时局部放宽雾（450 / 1700）与相机 far（2400），只影响本 spot。移动端总览仍偏小，细节靠正立面/水池机位。
- 40 calls 已接近正式线 <100；后续若增加折面/城市细节，仍应优先合并几何。
