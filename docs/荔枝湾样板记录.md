# 荔枝湾样板记录 · 2026-11-03

> 目标：按 **B 级** 做荔枝湾 · 西关水岸的河涌段 diorama，验证同一“博物馆展柜”风格能否处理“水面 + 三拱桥 + 文塔 + 西关大屋”的组合。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 为什么做龙津桥—文塔段

荔枝湾的核心不是“又一条水街”，而是同一画面里叠着：

- **一湾溪水**：“一湾溪水绿，两岸荔枝红”，2010 年揭盖复涌，2023 年完成滨水微改造；
- **龙津桥**：三拱石桥，长 **57m**，中间过水、两边行人，与文塔相呼应；
- **文塔**：六角形两层楼阁式，高 **13.6m**，龙津桥边“笔墨纸砚”节点的中心；
- **西关大屋**：青砖石脚、趟栊门、满洲窗；
- **荔枝湾大戏台**：原荔湾湖公园南门，后辟为大戏台，粤剧私伙局与节庆演出的水岸舞台；
- **两岸荔枝**：复植荔枝树，夏季红果，是“荔枝湾”名字的视觉来源。

官方口径里荔枝湾涌有 **十二座桥**（龙津、德兴、大观、至善、柔济、时敏、银钩、羽扇、多宝、抱月、叠月、虹月），本模型只做 **龙津桥** 一座，其余不进入近景。

## 2. 模型范围

- 模型是 **120×80m 水岸段 diorama**，压缩了约 **700m** 的荔枝湾涌复涌段。
- 包含：弯曲河涌、石驳岸/栏杆/麻石步道、龙津桥（三拱、桥面、台阶、栏杆）、文塔（两层六角、绿瓦、匾额）、4 栋西关大屋（趟栊门、满洲窗、青砖石脚）、3 间骑楼/商铺、荔枝湾大戏台、画舫、两岸荔枝/榕树、路灯。
- 不含：荔湾湖全园、泮塘五约、十二桥全线、粤剧艺术博物馆、永庆坊内部。
- 单位：1 unit = 1m；Y 向上；北 = -Z。
- 河宽约 18m，水深用 0.7m 的岸高差示意；真实河涌断面未测绘。

## 9. 已知取舍

- 只做龙津桥—文塔段；十二桥全线、荔湾湖、泮塘五约不进入近景。
- 河涌压缩到 120m，桥长 57m 压缩到 25m；桥与塔的比例为示意。
- 文塔用六角两层 + 绿瓦 + 匾额表示，未做内部旋梯/碑刻。
- 西关大屋用 4 栋典型段代表，趟栊门和满洲窗是程序化纹理。
- 荔枝树/榕树为低多边形，红果是色点，不是真实果序。
- 水面反射/倒影没有做实时反射，只用材质和水纹示意。
- OSM/测绘不可用，河岸线、桥位、建筑轮廓仍未核对。
