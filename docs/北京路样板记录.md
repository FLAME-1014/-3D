# 北京路样板记录 · 2026-11-03

> 目标：按 **B 级** 做北京路 · 千年古道的街段 diorama，验证同一“博物馆展柜”风格能否处理“街心遗址 + 连续骑楼 + 寺庙金顶”的组合。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 北京路的记忆点

北京路不是“又一条骑楼商业街”。它的唯一性是三件事同时出现在一条步行街上：

- **脚下的千年古道**：北段约 **44m × 3.8m**，11 层路面叠压，玻璃罩原址展示；
- **16m 街宽 + 连续骑楼**：2020 年修复 **376 栋**骑楼立面，保护建筑 67 栋；
- **大佛寺 / 普觉楼**：大殿面宽 **36.32m**、高约 **18m**；普觉楼 7 层，黄铜瓦金顶从骑楼后升起。

北京路全长 **1252m、宽 16m**；本模型只做 **80m 核心街段**，不是整条 1:1。

来源：

- 广州北京路文化旅游区官网《北京路千年古道遗址》（A）；
- 广州市政府《“变长变胖”，北京路更潮了！》（A）；
- 项目考据 `qoder-docs/superpowers/research/2026-10-31-beijinglu-facts.md`（B）。

## 2. 模型范围

- 模型是 **96×70m 街段 diorama**，核心是 80m 北京路 + 街心玻璃古道。
- 包含：80m 步行街、街心 11 层古道展柜、两侧 9 栋骑楼、大佛寺山门 + 普觉楼、古榕、跨街红灯笼、店招。
- 单位：1 unit = 1m；Y 向上；北 = -Z。
- 大佛寺在东南侧（+X、+Z），用 7 层收分塔楼 + 金顶剪影；不做法堂内部。
- 古道展柜为**抬升示意**：真实遗址在街面以下，模型抬到街面以上，便于在展柜视角看到 11 层剖面。

### 2.1 新增模板能力

北京路的细节机位需要比默认更近的相机，因此在 `spot.json` 的 `model` 下新增：

```json
"zoom": { "min": 4, "max": 260 }
```

`diorama.js` 读取后覆盖默认的 `maxDim * 0.28 / maxDim * 4.2`。没有这个配置的景点行为不变。

## 8. 已知取舍

- 街段只保留 80m，不是整条 1252m；两端用建筑收口，不做无限延伸。
- 古道展柜抬到街面以上，是“展柜”而不是“下沉遗址”的真实剖面。
- 11 层路面用 11 条逐层收分的深褐色带表示，近看能读到层理，远看更像一条深色玻璃带。
- 大佛寺只做山门 + 普觉楼体量，不做殿内佛像与完整院落。
- 骑楼立面用 9 栋典型段代表 376 栋，店招只保留少量可读字。
- OSM/测绘不可用，建筑轮廓与高度仍为示意；严格轮廓/比例需要正立面照片或实测。
- 361 calls 仍未到正式线 <100；后续用几何合并/实例化继续压。
