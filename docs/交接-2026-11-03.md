## 产品形态

Canton Atlas = 图鉴 + 单个地标 3D「博物馆展柜」模型 + 打卡。
不是全景、不是视频、不是连续城市。

- 模板：`canton-atlas/web/spot.html` / `spot.css` / `js/diorama.js`
- 数据卡：`canton-atlas/content/spots/<id>/spot.json`
- 模型：`canton-atlas/content/spots/<id>/model.js`
- 预览：`.../refs/preview/`
- 识别测试：`.../refs/recognition/README.md`
- 规范：`docs/景点建模规范.md`

## 注意

- 台湾/香港等不涉及；只做广州。
- 不发布、不覆盖 dist、不暴露凭据。
- 不要伪造 OSM/尺寸；拿不到就 `null` / `verified:false`。
- PowerShell `Set-Content -Encoding UTF8` 可能加 BOM；优先用 edit/write 工具，或 `UTF8Encoding($false)`。
- 新增预设名必须同时改：
  - `web/js/spot-contract.js` 的 `presetNames`
  - `web/js/diorama.js` 的 `PRESET_LABELS` 和默认 `presets`
  - `web/spot.css` 移动端隐藏列表
