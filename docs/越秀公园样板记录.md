# 越秀公园样板记录 · 2026-11-03

> 目标：按 **B 级** 做越秀公园山脊段 diorama，验证同一“博物馆展柜”风格能否处理“五羊石像 + 明城墙 + 镇海楼”的组合。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 为什么做“五羊—城墙—镇海楼”

越秀公园的不可替代性不在“湖 + 绿地”，而在同一段山脊上叠着三件东西：

- **五羊石像**：1959–1960 年建成，连基座高 **11m**、宽约 **10.8m**，130 余块花岗岩；主羊昂首衔穗，四羊环绕，是“羊城”的视觉来源；
- **明城墙（镇海楼段）**：1380 年建，镇海楼两侧核心段约 **170–200m**，青砖墙、红砂岩基、榕根抱墙；
- **镇海楼**：1380 年始建，五层重檐、高约 **28m**，首层 **31×15.77m**，红墙绿瓦，1929 年起为广州博物馆。

三者用一条登高线串起来，是别的公园复制不了的序列。三湖、体育场内部、博物馆展陈不进入本模型。

---

## 2. 与 `zhenhai` 条目的关系

图鉴另有「镇海楼」条目（id `zhenhai`），与本模型重叠。

- 本模型把镇海楼作为越秀公园山脊段的**端景**，不做楼内展陈；
- 后续若要给 `zhenhai` 做独立入口，建议直接复用同一模型页，用 `preset=zhenhai` 打开，而不是再做一套几何；
- 这次先保证 `yuexiu-park` 可用，`zhenhai` 仍走旧入口，等双视图方案确定后再切。

---

## 3. 模型范围

- 模型是 **110×80m 山脊段 diorama**，压缩了五羊—镇海楼约 **300m** 的真实间距。
- 包含：五羊石像与岩座、明城墙（镇海楼段 + 榕根 + 墙顶榕树）、镇海楼（五层重檐 + 前平台/石阶/石狮/古炮）、简化五羊仙庭牌坊、石径、低多边形榕树/香樟、岩石露头。
- 不含：东秀/南秀/北秀三湖、体育场内部、中山纪念碑近景、镇海楼内部展陈。
- 单位：1 unit = 1m；Y 向上；北 = -Z。

## 9. 已知取舍

- 山脊段只保留五羊—城墙—镇海楼，不含三湖与体育场；因此不是“整座越秀公园”的全貌。
- 真实 300m 间距压缩到 110m，镇海楼与五羊同框是**示意**，不是实际距离。
- 五羊岩座与羊群用低多边形花岗岩色块；远看能读“五羊 + 岩座”，近看仍偏抽象。
- 明城墙压缩到约 92m；榕根用 9 条垂根示意，未做完整根系。
- 镇海楼内部、门票闸机、展陈、库房不做；只做外观、前平台/石阶、石狮、成排古炮。
- 五羊仙庭只做简化牌坊，不编造浮雕内容与文字。
- 地形/树木颜色偏浅，是共享展厅灯光的結果；后续可单独压暗材质。
- OSM/测绘不可用，建筑轮廓、城墙走向与高度仍未核对。
