# 同图探索：地图操作与标签分级（2026-11-02）

## 本轮实现
- 地标标签优先于城市背景标签；当前选择优先级最高。按屏幕碰撞与面板避让选择，桌面最多 6 个、窄屏最多 3 个。远景只保留高等级背景，近景隐藏背景标签。使用实际 DOM 尺寸检查边界，标签并非建筑深度遮挡检测。
- 默认单指/左键环绕；平移模式、右键或 Shift 拖动平移；WASD 平移；双指质心平移与捏合缩放。区域平移限于示意地图范围，区域总览恢复初始镜头。
- 处理双指结束后的单指续拖和误点击抑制、丢失指针捕获。窄屏初始收起详情，可展开滚动；短横屏将详情放在右侧，避免与底部状态重叠。
- 标签与状态界面约 5 Hz 更新，渲染仍独立执行。后台暂停渲染，恢复时重置帧间隔统计。HUD 区分 fps、CPU render、frame 间隔，并显示可见/焦点状态。

## 已验证
- 浏览器实际视口 390×844、320×740、844×390；搜索筛选、大剧院/省博切换、详情折叠，稳定状态无横向溢出。修正横屏面板与页脚重叠；320 宽视角栏与页脚保持分离。
- 桌面平移拖动和 W 键改变 HUD 的 target 值；总览恢复入口。POI 列表两地标均返回餐饮 6 条；本次未执行外部导航。
- 前台总览观测约 60 fps，34 calls / 1,720 tris；大剧院窄屏细模约 60 fps，41 calls / 3,388 tris；省博桌面档细模约 60 fps，57 calls / 18,330 tris。稳定样本 CPU render 约 0.3–0.7 ms，frame 约 16.7 ms。这些是当前机器的短时观测，不是持续或真机性能保证。
- 新增标签优先级、避让、边界、数量上限、间距与平移比例/方向单元测试。

## 仍需验证 / 不应误判
- 没有物理手机测试，双指连续手势、系统手势冲突、移动端软键盘、安全区与真实 GPU 性能仍待真机验收。右键/Shift 拖动路径已有实现，本次浏览器手动测试集中在平移模式和键盘。
- 先前曾出现 1 fps 而 CPU render 仅约 0.4 ms 的样本：可能涉及浏览器调度/遮挡节流，但尚无确切根因。CPU 提交耗时不等于 GPU 耗时；不能据此排除 GPU 问题或宣布低帧率已修复。
- 暂不根据低 FPS 自动降质量，避免后台节流误触发。未来应在普通浏览器前台、真机及持续模型切换下采样，并补 GPU/主线程分析。
- 底图仍是区域样板，不是完整广州实景或测绘地图。未同步历史 dist 或发布线上站点。
