## 1. 摩星岭的记忆点

- **“摩星岭”石门**：山脚门岗，石构三间、方形石柱、平石梁，中上方竖匾刻“摩星岭”，两侧低石墙；门后是又长又陡的石级。
- **吉星石**：门岗约 100 m 处，高约 6 m、宽约 4 m，合“十全十美”之意，石面刻“摩星岭”。
- **锦绣南天石牌坊**：登顶石级中段的白石三间牌坊，金瓦顶、金匾“锦绣南天”；朱德 1965 年题写。
- **2024 年栈道 + 扶梯**：约 150 m 钢栈道 + 两段总长约 60 m 自动扶梯，垂直抬升约 26 m，位于步梯西侧；浅灰钢构、深灰桥面、竖向密条栏杆、白色 A 形钢架 + 玻璃顶棚 + 暖色灯带。
- **星形指北碑**：山顶标志，墨绿方尖碑上置五角星形花岗岩块，星面朝北刻“1900km 北京”，碑身朝南刻红字“海拔382米”，基座挂红色许愿带与锁。
- **山顶观景亭**：山顶东侧白色圆亭、深灰攒尖顶；游记中有“摘斗亭/山顶亭”等不同叫法，模型只写“山顶观景亭”。
- **南望城市**：山顶南侧可见广州塔、珠江新城与珠江；模型只做压缩剪影和薄雾，不表示实测方位与距离。

来源：搜狐（2026-09）、百度百科、美篇（2025-07 栈道/扶梯、2025-04 牌坊）、8264 游记、360doc（B/C，多源交叉）。详细条目见 `canton-atlas/content/spots/baiyun/spot.json`。

## 2. 模型范围

- 模型是 **120×90m 登顶段 diorama**，不是 21.8 km² 白云山 1:1，也不是 382 m 高差实测，更不是山顶广场/白云晚望。
- 包含：南侧方格铺装广场、摩星岭石门、吉星石、陡石级（下段/上段）、中段平台与锦绣南天石牌坊、西侧栈道/双段扶梯与玻璃顶棚、山顶平台、星形指北碑、许愿带/锁、锁爱台、祈福架、白色圆亭、南缘城市与珠江剪影、台地绿化/树木/灯柱/石凳。
- 布局约定：南 = `+Z`，北 = `-Z`；石门在 `z≈22.5`，吉星石在 `x≈18, z≈27.5`，中段平台/牌坊在 `z≈2`、`y≈7.2`，扶梯在 `x≈-13.6`，山顶平台约 `y=13.2`、`z≈-22.5`，星形指北碑在 `z≈-23.5`，白亭在 `x≈9.8, z≈-26`，城市剪影在 `z≈39–44`。
- 真实山顶平台、台阶、栈道、牌坊和建筑轮廓尚未测绘；台地、城市和珠江的压缩关系是**为了画面可读性做的示意排布**，不应当作精确总平面。
- 不含：白云山其余 30 多座山峰、云台花园、山顶广场/白云晚望、摩星岭售票/门岗建筑内部、索道。

## 4. 实测

- **总览：350 draw calls / 21,086 triangles**（1600×1000，软件 WebGL）。
- 其他机位：门楼 301 calls / 18,108 tris；牌坊 260 calls / 17,620 tris；山顶 349 calls / 21,074 tris；细节 308 calls / 20,302 tris。
- `__SPOT_API__.bench(90)`：**约 18–21 ms/frame**（页内视口；软件渲染）。
- 页面可加载，无控制台错误；`node --test scripts/spot-model.test.mjs` 17/17 通过；`node scripts/check.mjs` PASS。
- 五机位、六热点、iframe 进入、标记去过同步、返回图鉴、移动端 390×844 已验证；移动端无横向溢出。

## 8. 已知取舍 / 待改

- 场地边界、山顶平台、石级、栈道/扶梯和牌坊均未测绘；`dimensions.footprintM` 保持 `[null, null]`，模型 `footprintM` 的 `[120, 90]` 是 diorama 段尺寸。
- 台地是风格化层叠体量，不是现场等高线；石级宽度、坡度、踏步数按画面调整，未逐级计数。
- 吉星石用低多边形岩体 + 红字示意，未复刻真实石形与刻字位置。
- 牌坊为白石 + 金瓦 + 金匾的简化三间，未做真实木构斗拱、瓦垄、对联原文。
- 扶梯为双段钢构 + 玻璃顶棚示意，未做真实梯级机械、玻璃分格和 V 形支撑细节。

- 城市与珠江为压缩剪影；广州塔、珠江新城、珠江的相对位置和高度不作为实测方位。
