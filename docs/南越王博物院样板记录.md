## 1. 南越王墓展区的记忆点

- **红砂岩石阙正立面 + 一线天**：临解放北路是一整面约 36m 宽、约 12m 高的红砂岩墙，中央开一条约 2.6m 的玻璃缝，顶部收成半圆拱并嵌铜蟠龙圆饰；门额刻“南越王博物院”，墙前是高台阶，两翼台地伏卧一对石虎。
- **8m 男女越人浮雕 + 一对圆雕石虎**：墙面是潘鹤所作男女越人，头顶日月、赤足踏蛇；石虎呈伏卧欲跃之势，原型分别取自墓中屏风构件、玉璧与错金铭文虎节。
- **象岗山依山而建**：入口到岗顶高差约 15m，红砂岩挡墙、台阶和绿化串起上山序列；综合陈列楼另一端以 44 级蹬道连接墓室原址。
- **覆斗形玻璃光棚**：墓室原址保护罩，仿汉武帝茂陵覆斗形，钢架金属玻璃；约 460㎡，周围回廊约 550㎡。
- **主体陈列楼 · 玉圭门阙**：北侧高耸玉圭形门阙，地下一层金字塔状光棚，东西墙船纹浮雕呼应出土船纹铜提筒。
- **南越文王墓**：1983 年发现，坐北朝南，南北 10.85m、东西最宽 12.5m、约 100㎡、七室；墓顶距岗顶约 20m；出土文帝行玺、丝缕玉衣。

来源：广州市越秀区人民政府、南越王博物院、人民日报海外版、广州市人民政府、广州日报（A/B）；莫伯治建筑师事务所（项目公开）；高德地图与 OSM 未完成核对。详细条目见 `canton-atlas/content/spots/nanyue-museum/spot.json`。

## 2. 模型范围

- 模型是 **120×80m 场地段 diorama**，不是 9,668㎡ 王墓展区 1:1，也不是王宫展区（中山四路 316 号）。
- 包含：解放北路街道段、临街石阙与一线天、石虎、综合陈列楼、象岗山台地/挡墙/蹬道、覆斗形墓室光棚与回廊、主体陈列楼与玉圭门阙、花坛、树木、灯柱。
- 布局约定：解放北路在 `+X`，石阙正立面在 `x=37`，入口台地 `x=37..47`，墓室光棚在 `x=-28`，主体陈列楼在 `x=-28, z=-28`，44 级蹬道在 `z≈24`。真实边界与建筑轮廓尚未测绘，东西/南北关系是**为了画面可读性做的示意排布**，不应当作精确总平面。
- 不含：墓室内部七室、王宫展区、完整 9,668㎡ 边界、综合陈列楼/主体陈列楼内部展厅。
