# 粤剧艺术博物馆样板记录 · 2026-11-03

> 目标：按 **B 级** 做粤剧艺术博物馆 · 广福台的园林段 diorama，验证“水院 + 戏台 + 镬耳墙/满洲窗”的岭南园林表达。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 为什么是“水院 + 广福台”

粤剧艺术博物馆不是“一个展厅”，它的唯一性是：

- **水院**：岭南园林“连房广厦”布局，十字轴骨架环绕中心水院；廊桥、戏台、展厅连成一体；
- **广福台**：临水戏台，纯木雕、紫铜瓦屋顶、木面贴金，由非遗传承人何世良修建；
- **镬耳墙 / 满洲窗**：岭南园林的建筑符号；
- **主馆 + 展厅**：粤剧唱腔、行当、戏服、剧本与唱片；
- **恩宁路 / 荔枝湾涌**：博物馆就在西关水岸，和永庆坊、荔枝湾连成一片。

官方口径：恩宁路 127 号，2016-06-08 开放，总用地 1.72 万㎡、建筑面积 2.17 万㎡，沿荔枝湾涌分南北两岸。

---

## 2. 模型范围

- 模型是 **120×80m 园林段 diorama**，取南岸主馆 + 水院 + 广福台。
- 包含：椭圆水院、广福台（紫铜瓦屋顶、金漆木雕屏、匾额、临水台阶）、主馆（玻璃竖带 + 镬耳山墙）、侧厅（双镬耳 + “粤剧展厅”）、园林门楼、南廊/东廊（连续柱列 + 满洲窗）、石桥、荷叶、榕树/竹/芭蕉。
- 不含：北岸文物修复区、展厅内部、整块馆区、真实演出排期。
- 单位：1 unit = 1m；Y 向上；北 = -Z。

## 8. 已知取舍

- 只做南岸主馆 + 水院段；北岸、展厅内部、整块馆区不进入近景。
- 水院为椭圆示意，真实岸线、桥位、廊桥走向未测绘。
- 广福台用简化木雕屏/紫铜瓦屋顶表示，未做真实木雕纹样与内部。
- 主馆/侧厅的镬耳墙、满洲窗为体量示意；戏服、剧本、唱片等展陈不建模。
- 演出信息以馆方公告为准，模型不写固定场次。
- OSM/测绘不可用，馆区轮廓仍未核对。
