# 省博 POI 功能阶段 · 2026-11-02

## 功能

- 靠近省博时首次查询，餐饮050000/购物060000分类，各最多6条，周边800米。
- 查询中心由高德搜索“广东省博物馆”、限定广州取得；不把FusionGeo的WGS84坐标直接用作高德GCJ-02。
- 展示名称、地址、类型、接口返回距离；缺少坐标的结果不生成外链。
- 高德URI链接使用返回坐标和coordinate=gaode，新页面显示地点并可由用户设为终点；不自动申请位置权限、不提供站内路线。
- 5分钟页面内缓存，分类请求序号防止晚返回覆盖当前分类。
- SDK/插件/查询超时、无数据、配置错误、已识别域名/Key拒绝提示及手动重试。
- 使用textContent生成外部数据，链接固定高德域名且noopener/noreferrer；不记录凭据。

## 验证

- 42个JS语法与70个本地HTML引用检查通过。
- 3项自动测试通过：坐标系统、POI归一化/链接/异常坐标、静态服务。
- 浏览器餐饮真实返回6条：包括艺外咖啡馆、利口福等，地址和接口距离出现。
- 切购物真实返回6条：包括粤博文创、便利店、工美文创店等。
- 检查首条外链跳转高德目的地，页面显示“粤博文创”和“设为终点/设为起点”；未执行路线、不登录、不处理验证码。
- 查询期间浏览器错误日志为空。

- 尚未自动模拟SDK失败/无结果/分类请求竞态；完整网络故障和手机实机验收仍待进行。
