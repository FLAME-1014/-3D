## 1. 中山纪念堂的记忆点

- **八角宫殿式会堂**：中央八角攒尖顶 + 四出重檐歇山抱厦；宝蓝琉璃瓦、红柱、乳黄墙、白花岗岩台基；
- **大跨度**：堂高 48.63m、南北 72.65m、东西 63.32m，大厅净跨 71m，内部无柱；
- **门楼—草坪—华表—铜像—纪念堂**：一条完整的到达序列；
- **孙中山铜像**：像高 5.5m、重 3.9t；1956 年创作，1998 年翻铸全铜；
- **云鹤华表**：一对，1931 年建；花岗岩，柱头祥云/仙鹤；
- **木棉王**：东北角，350 多年树龄，高约 27m、冠幅约 33m；
- **北侧中轴**：越秀山/中山纪念碑方向，模型只做低山 + 碑体远景提示。

来源：广州市林业和园林局、越秀区政府（A）；《中国大百科全书》（B）；项目考据。

---

## 2. 模型范围

- 模型是 **140×110m 场地段 diorama**，不是 6.1 万㎡ 全场地 1:1。
- 包含：正门楼（三拱）、草坪/中轴石板路、孙中山铜像、云鹤华表一对、蓝顶纪念堂（八角主体 + 四出抱厦 + 三层蓝瓦 + 金宝顶）、木棉王、白玉兰/榕树、北侧低山与碑体远景。
- 不含：会堂内部（4729 座/舞台）、东西附楼、完整近代中轴。
- 单位：1 unit = 1m；Y 向上；北 = -Z。

- 北侧中轴只做低山 + 碑体远景，不重建中山纪念碑/镇海楼。
- 场地压缩到 140×110m，门楼—铜像—会堂的真实进深比例未测绘。
