# 沙面样板记录 · 2026-11-02

> 目标：按 **B 级** 做沙面岛段 diorama，验证同一“博物馆展柜”风格能否处理岛屿、水面和欧陆建筑。  
> 结论：**B 级通过（识别 lite）；A 级严格轮廓/尺度未做。**

---

## 1. 先回答：沙面是沙面岛吗？

是。**沙面就是沙面岛**：珠江白鹅潭北侧的江心岛，荔湾区，面积约 **0.3 km²**，东西约 **862m**、南北约 **287m**。

- 1859 年英法迫使清政府开挖沙基涌，使其成为人工岛；1861 年签订《沙面租借条约》。
- 岛上是“三横五纵”街巷：沙面北街、沙面大街、沙面南街 + 沙面一街至五街。
- 留存 **150 多栋欧洲风格建筑**，其中 **54 栋文物建筑**，是全国重点文物保护单位。
- 沙面大街全长 **846m、宽 12.9m**，两侧集中最精华的历史建筑，沿街 53 株古树。
- 代表：露德圣母堂、沙面基督堂、白天鹅宾馆（28 层、结构 99.9m）、沙面公园/白鹅潭江岸。

来源：广州市政府《沙面历史文化街区保护活化工程报告公示》（A）；项目考据 `2026-10-30-shamian-facts.md`（B）。

## 2. 模型范围

- 模型是 **96×70m 岛段 diorama**，不是全岛 862×287m 的 1:1 复原。
- 包含：水面、岛体驳岸、沙面大街林荫轴线、8 栋欧陆街区建筑、露德圣母堂、沙面公园、南岸栏杆/古榕、白天鹅塔楼剪影、北侧两座桥。
- 单位：1 unit = 1m；Y 向上；北 = -Z。
- 白天鹅按 **边缘塔楼剪影** 处理，不做 99.9m 完整建筑；露德圣母堂尖塔为照片比例示意。
