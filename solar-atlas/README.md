# Solar Atlas · 太阳系图谱

参考 https://solar-system-atlas.pages.dev/ 的视觉语言与探索路径，重新编写的独立本地项目。运行时采用原生 ES Modules、Three.js 与 Node.js；行星贴图和星表保存在本地。

## 启动

需要 Node.js 20 或以上，以及支持 WebGL 的 Chrome / Edge。

```powershell
cd C:\Users\Administrator\Desktop\ycjd\solar-atlas
npm run dev
```

打开 **http://127.0.0.1:4208/**。也可以双击本目录的 `启动图谱.cmd`，再打开终端里显示的网址。Ctrl+C 停止服务器。

如果端口已被占用：

```powershell
$env:SOLAR_PORT = '4210'
npm run dev
```

基础运行不需要安装前端依赖，Three.js 已随项目保存。请使用 HTTP 服务器打开，不要直接双击 `index.html`，以免浏览器阻止模块与贴图加载。

## 已实现

- 黑金色首页、三维轨道背景、环形加载界面、环境音乐与中英文主导航。

- 全局搜索、键盘选择、天体档案、画质设置、沉浸观看与可复制的探索链接。
- 88 个星座连线、实际恒星目录与 10 个精选深空天体档案。
- 磁层、日球层、地球—金星共振网、洛希极限、光行时、宜居带等科学图层。
- 真实尺寸与距离比例的飞行模式：推进、平移、对准、自动驾驶、引力仪表与目标导航。
- 地球摄影贴图、12 条命名洋流、模型风带与降水可视化。

- 位置搜索、经纬度导航、Open-Meteo 位置气象查询，以及 NOAA SWPC 太阳风查询。
- 390 像素窄屏适配、底部模式导航与可展开任务抽屉。

## 数据与复刻范围

当前实现还原主要界面与操作路径，并使用独立的本地代码、精选资料和明确标注的模型。它没有完整搬入参考站的 206 项任务、16 万真实小行星、在轨卫星目录、DSN 实时波束或完整天气栅格数据。

- **图谱模式**分别压缩尺寸与距离，且以示意方向排列行星，方便观察。
- **三维 / 当前日期模式**使用固定基础根数与开普勒方程近似，未包含完整摄动，不属于高精度 JPL 实时星历。
- **小行星带**包含 6,000 个生成的示意粒子，不宣称是真实对象目录。
- **航天器标记**是关联天体附近的示意位置，档案明确标注“历史 / 示意位置 · 非实时”。任务状态是静态科普记录。
- **深空**使用保存的影像和天球方向，不是所在地的当前地平天空。当前版本绘制星座线，没有搬入参考站的整套星座人物插画。
- **飞行模式**以 50 场景单位 = 1 AU 为长度映射，使用真实天体半径和简化牛顿引力；飞行计时独立于历法时间。自动驾驶是辅助导航，不是燃料受限轨道任务规划器。
- **洋流、风带、降水、温盐曲线**为清楚标注的科普模型，不是当前实测。物种档案使用图形符号，没有内置物种摄影素材。
- **位置气象与太阳风**由 Node 服务向公开上游查询，显示有效时间和单位。无网络或上游不可用时明确提示，不生成假观测值。
- **双语**覆盖首页、主导航、搜索名称等；详细科普正文目前以中文为主。

素材出处与许可信息见 [ATTRIBUTION.md](./ATTRIBUTION.md)。项目没有复用原站压缩后的前端应用代码。

## 检查

当前工作区已有 Playwright。若单独复制此目录，先安装测试依赖，并确保本机安装 Chrome：

```powershell
npm install
npm run check
npm test
```

`npm run check` 检查 JavaScript 语法、ID、轨道周期与距离边界、本地贴图和星表。

`npm test` 启动临时本地服务器和无界面 Chrome，检查主要操作流程、天气成功与失败界面、手机布局、直接链接恢复以及服务器路径边界。天气测试使用固定响应验证界面，不依赖上游持续在线。

截图与结果写入 `output/`，该目录已在 `.gitignore` 中排除。需要使用另一 Chrome 通道时，可设置 `SOLAR_CHROME_CHANNEL`。

## 文件结构

```text
index.html              页面结构、无障碍标签和图标
styles.css              桌面与移动端样式
src/app.js              界面状态、资料面板、搜索与 API 查询
src/scene.js            Three.js 场景、镜头、轨道、科学图层和飞行
src/data.js             天体、任务、海洋资料与轨道计算
server.mjs              静态服务器与两个公开数据代理
assets/textures/        本地行星、云层与银河贴图
assets/catalog/         星座、恒星与深空目录
assets/vendor/          Three.js 与 OrbitControls
scripts/                素材下载、静态检查与交互验证
```

新增天体、任务、物种或洋流时，优先扩展 `src/data.js`，并保留资料来源及数据性质说明。

## GitHub Pages

本项目在现有仓库网站中的入口为 **https://flame-1014.github.io/-3D/solar-atlas/**。

仓库根目录运行 `node scripts/build-solar-atlas-site.mjs`，将页面、源码和本地素材复制到 `canton-atlas/web/solar-atlas/`。GitHub Pages 工作流会自动执行该步骤，发布到站点的独立子路径。

发布版的 `config.js` 使用 `dataTransport: 'direct'`，通过浏览器直接查询支持跨域的公开服务；本地版继续使用 Node 数据代理。上游不可用或不允许跨域时，界面显示数据不可用，主场景仍可使用。Node 服务器、开发依赖、日志及测试输出不会上传到网站。
