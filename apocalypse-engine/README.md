# APOCALYPSE ENGINE

GitHub Pages 入口：[打开子午港实验室](https://flame-1014.github.io/-3D/apocalypse-engine/)。合并到 `main` 后，仓库的 Pages 工作流会将生产构建发布到这个子目录。

一个在浏览器实时运行的沿海灾害响应数字孪生实验室。使用 Three.js 进行 3D 场景渲染、Rapier 进行可碰撞刚体计算，并以独立可重复的计算模型更新洪水、地震和台风。

## 启动

需要 Node.js 22.12 或更高版本。

```powershell
cd apocalypse-engine
npm install
npm run dev
```

打开 <http://127.0.0.1:5180/>。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。

## 操作

- 拖动鼠标旋转场景，滚轮缩放，右键拖动画面。单击城市地面或建筑查看水深与结构状态。
- 左侧切换洪水、地震和台风，并调整该灾害的数值参数；选择会原子复位当前情景。
- 底部可启动、暂停、继续、单步推进及切换 1×、2×、5× 模拟速度。暂停冻结时钟、灾害方程和 Rapier 步进；单步只前进一个固定步长。
- 运行期间可以保存最多六个完整检查点，并从确定性检查点重放时间轴。
- `?faults=1` 仅在 Vite 开发服务器启用故障测试台；每个按钮隔离运行一项引擎回归。正式构建不包含该测试台。

## 验证

```powershell
npm run typecheck
npm test
npm run test:e2e
npm run test:soak
```

`npm test` 运行固定种子的算法、状态机、物理检查点及八项故障回归。`npm run test:e2e` 需要 Windows 本机 Google Chrome 和可用的 WebGL 2 驱动。连续五分钟混合灾害测试使用相同的 Chrome 和 GPU；实测结果保存在 `reports/performance-soak.json` 和 `reports/performance-report.md`。故障回归证据 JSON、Playwright JSON 摘要和桌面/移动场景截图也保存在 `reports/`。

## 架构

```text
src/
  core/        Engine、场景、时钟、渲染、WebGL 水面、资源管理
  city/        种子地形、程序化城市、道路、桥梁、建筑结构与损伤
  physics/     固定步进 Rapier 世界、碰撞、刚体、坍塌碎片、完整快照
  disasters/   洪水网格、地震响应、台风阵风和参数边界
  state/       非法状态跳转保护与集中状态同步
  analytics/   实况统计、灾害时序数据和事件日志
  ui/          响应式操作台、图表、时间轴、检查点和水深探针
  testing/     独立故障回归与只在开发模式加载的故障注入台
tests/
  unit/        确定性算法、状态和八项真实子系统回归
  browser/     WebGL、交互、移动布局和 5 分钟运行检查
```

## 模型与限制

- 地面采用约 4 m 分辨率的程序化高程场。洪水将邻接单元自由表面高差转换为受供体蓄水量限制的横向通量，加入空间变化降雨径流和基于排水沟、泵站的汇流/排水项。海岸和河口作为指定水位边界；水深场以顶点数据实时上传到 GPU，渲染动态波纹、岸线和水深等高线。
- 洪水是**浅水质量交换的工程近似**，不是完整二维浅水偏微分方程求解器；没有显式动量平流、破波、河床沉积、排水管网连通求解或标定后的地理城市数据。雨量转换采用等效径流系数，水位表示边界潮位基准，不宜用于真实风险决策。
- 地震使用可调频率、位移和持续时间的合成地面加速度输入楼体弹簧－阻尼振子。不同建筑由独立结构类型、频率、阻尼和漂移限值控制。此结构损伤只是概念性的漂移阈值累积，不是经工程审核的有限元、规范验算或实测地震烈度预报。
- 台风采用种子确定的相关阵风曲线、风向、二次风载、树冠摆动和雨滴场。轻质刚体使用简化平方气动阻力；建筑抗风和空气动力学不包含 CFD、规范压力系数或地形边界层。
- Rapier 使用真实 3D 重力、固定／动态刚体、碰撞体、摩擦、CCD 和系绳关节。碎片与地面/建筑及碎片彼此碰撞。建筑整体在损伤阈值处转为多块有限数量的碰撞刚体，是受预算约束的分块坍塌近似。
- 物理使用 1/60 s 固定步进，洪水网格以 1/15 s 运行。检查点保存 Rapier 二进制世界快照、地形水深场、建筑损伤、固定时钟和事件/遥测；确定性回放同时重放记录下来的参数和停止命令。

## 性能指标

场景使用复用程序几何和材质、树木/基础设施/碎片实例批次、视锥裁剪、远景 LOD、固定物理对象预算、有限粒子数及低／中／高自适应质量。面板和测试探针记录 FPS、P95 帧时、绘制调用、三角形数、GPU 几何体/纹理数、物理对象数，以及浏览器提供时的 JS 堆用量。

浏览器的可用 GPU、散热、驱动和电源策略会改变帧率；短时间或未记录实际运行的性能估计不构成性能验收。参考测试机器和连续五分钟实测数据请见 `reports/performance-report.md`。
