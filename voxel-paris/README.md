# 巴黎场景源码原型

本目录保存 4 个尚未完整组装的 Three.js 场景模块：

| 文件 | 内容 |
| --- | --- |
| `src/01-core.js` | 渲染器、随机数、基础参数与批次工具 |
| `src/02-island.js` | 岛屿场景 |
| `src/03-city.js` | 城市场景 |
| `src/08-post.js` | SSAO、泛光、雾效和色调映射 |

这些模块依赖共享的 `THREE` 和场景上下文。当前目录没有完整入口、模块装配和动画循环，不能直接作为可运行项目启动。

本次归档只验证了 4 个文件的 JavaScript 语法，没有补写缺失模块，也没有完成浏览器画面验收。
