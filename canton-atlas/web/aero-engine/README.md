# AERIS · 航空动力实验室

基于 Three.js 的中文航空发动机交互展台。页面、模型、控制器与 three.js 依赖都保存在本地；打开页面时不依赖 CDN、外部字体或第三方模型接口。

## 启动

在仓库根目录运行：

```powershell
npm run dev:engine
```

访问 **http://127.0.0.1:4190/aero-engine/**。专用启动命令也会把 `/` 转向发动机展台。

如果已经运行 `npm run dev`，可直接访问 **http://127.0.0.1:4188/aero-engine/**。这两个入口共用同一个预览服务，不改变原有广州项目页面。

端口冲突时可指定另一个端口：

```powershell
$env:PORT = '4191'
npm run dev:engine
```

也可将本目录整体交给普通 HTTP 静态服务器托管。请使用 HTTP/HTTPS 访问；浏览器对 `file://` 页面的 ES modules 有限制。

## 交互

- **结构探索**：鼠标拖动 / 单指旋转，滚轮 / 双指缩放，右键拖动平移。点击模型、锚点或部件列表，查看构造、原理、材质与参考参数；可继续进入风扇叶片、压气机转子、喷油旋流杯、双转子轴系、排气尾锥和滑油管路六处细节。标注优先显示当前讲解对象，并进行遮挡判断与面板避让。
- **爆炸视图**：六个功能模块沿轴线展开，附件系统向下侧分离。连续滑块控制 0–100% 展开距离，支持平滑复原与自动构图。
- **分步拆解**：七个教学步骤，含概览、进气端、压气机、燃烧室、涡轮、排气、附件系统。每一步独立移动对应模块，已经拆出的模块保持位置，后续模块仍保持装配；反向切换可逐件装回。支持跳步和每步六秒的自动播放。教学拆解路径与自由探索的轴向爆炸滑块相互独立。
- **工作原理**：吸入、压缩、燃烧、做功与排气四个阶段，镜头与气流重点随阶段变化；冷色显示进气及外涵流，暖色显示燃烧后的核心流。高、低压轴系以不同示意速度运转，可以暂停。在当前原理阶段打开详情不会退出演示；若临时聚焦部件，关闭详情会恢复查看前的镜头。
- **观察工具**：剖面开关、标注开关、聚焦、镜头复位、缩放、自动环绕与全屏。
- **键盘**：`R` 复位，`C` 剖面，`L` 标注，`F` 全屏，`← / →` 切换拆解步骤，`Space` 播放 / 暂停当前演示，`Esc` 关闭部件说明或侧栏。

手机端提供可收起的部件侧栏、操作指南和可滚动的详情面板；主要操作按钮拥有 44px 触控范围，正文为 13–14px，拆解长文可通过「阅读完整讲解」展开。隐藏浏览器标签页时停止自动演示；遵循系统的减少动态效果设置。WebGL 不可用时展示提示，同时保留组件与原理资料。

画质可选择「自动适配」「细节优先」「流畅优先」。场景静止、转子停止且镜头阻尼结束后会停止请求动画帧，操作时重新唤醒；自动档根据设备与持续动画帧耗时调整渲染档位。性能统计只统计连续动画帧，不把静止休眠算作慢帧。

## 模型与准确性

模型以 **CF6–80C2 级高涵道比双转子涡扇发动机**的结构原理为参考，采用程序化几何：

- 扭转宽弦风扇叶片、整流锥、进气唇口与导向叶片。
- 4 级低压、14 级高压压气机与对应静子，轴向逐级缩小的压气机构型。
- 连续环形燃烧腔、短喷油旋流杯、冷却孔、供油总管与可拆机匣。
- 2 级高压、5 级低压涡轮转子，以及贯穿并对齐的双轴分段。
- 可剖开的短外涵导流段、分流环与出口唇口，以及核心尾锥、排气喷管。
- 接头、螺栓、附件壳体、燃油 / 滑油等外部示意管路。

压气机与涡轮级数参照 GE Aerospace 官方 CF6–80C2 比较表；这只校对了级数，不代表叶型、尺寸或装配细节已经校准。实际生成叶排的轴向包围盒经过间隙检查，未发生叶排轴向重叠。

钢、钛和热端分别使用程序生成的底色、粗糙度与凹凸纹理，共九张纹理，配合预过滤环境反射及工作室灯光。重复叶片、螺栓与冷却孔使用实例化，静态构件按材料合并。默认剖视约 **30.5 万个三角形、133 个模型网格**；含地面、气流和其他场景物体时，最终渲染统计会变化。

**当前是可交互的教学示意模型，不是制造商原始 CAD、原机材质扫描或经测量验证的 1:1 数字孪生。** 虽然压气机与涡轮级数已有公开依据，叶片数量、装配间隙、零件形状与动画速度仍有可视化简化。场景使用示意模型单位，资料卡中的近似实际参数不作为当前网格的量尺。爆炸位移用于讲解，不代表真实维修顺序。

如需工程级 1:1 对照，应提供具备使用许可的 CAD / STEP / 高精度 GLB、明确子型号和材质参考。可将其转换为以 `fan`、`compressor`、`combustor`、`turbine`、`nozzle`、`accessories` 命名的六个组件组，在 `engine-model.js` 中替换几何，并保留相同接口；这样可以复用现有交互、镜头和资料面板。

权威参考来源与真实资产接入约定见 [REFERENCE-ASSETS.md](REFERENCE-ASSETS.md)。参考网页用于核对概念与公开资料，不替代具体子型号的 CAD、尺寸及材质依据。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` / `styles.css` | 展台布局、响应式样式、图标与弹窗 |
| `app.js` | 模式与步骤状态、资料展示、输入交互 |
| `engine-viewer.js` | 渲染、灯光、镜头、射线选取、气流、资源释放 |
| `engine-model.js` | 可分离的程序化发动机组件与材质 |

## 验证

在仓库根目录执行：

```powershell
npm run test:engine
npm run check
npm test
```

`test:engine` 使用已安装的 Playwright 和本机 Chrome，自动启动临时预览服务，检查 WebGL 渲染、实际镜头移动、部件说明、爆炸滑块、原理上下文保留、逐件拆解与反向装回、细节导航、静止休眠与唤醒、画质切换、对话框、手机导航和降级状态。结果和截图写入 `output/aero-engine/`。也可通过 `--base=http://127.0.0.1:4190` 指向正在运行的预览服务。

报告包含本机 Chrome 动画场景的 FPS、P95 帧间隔、渲染资源数量，以及 390px 模拟手机视口的同类数据。**模拟手机视口不是实际手机性能测试**，不能据此宣称真实 iOS / Android、Safari 或所有低端设备达到相同帧率。交付前应根据目标机型补测持续旋转、拆解和气流演示，确认画质、温升和长时间资源占用。

维护时可在浏览器控制台调用 `window.aerisDiagnostics()` 查看当前交互状态、相机参数和渲染统计。
