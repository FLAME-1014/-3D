## 输入资产约定

- **几何与构型**：优先提供具有使用许可的 GLB；也可提供 STEP 及转换后的 GLB。附具体型号、构型版本、源文件版本和转换记录。须保留装配层级、零件身份、法线、硬边及关键配合结构，不能将整机合成一个不可拆分网格。
- **单位与坐标**：交付 GLB 使用米。记录源单位、转换比例和至少一个可核验尺寸；应用缩放后再验收。接入场景以 X 为主轴，进气端为负 X，Y 向上；保留各模块合拢位置与局部原点，动画位置使用相对合拢原点的偏移，旋转使用 XYZ 欧拉角、弧度。
- **六个功能组**：保留以下稳定名称。高低压转子、机匣、轴段、轴承、静子和管路仍应保留可独立识别的子节点。按功能组组织不等于认可其为真实维修拆装单元。
- **表面与纹理**：保留独立材料槽与 UV；金属、涂层、热端、线束不共用一张通用纹理代替原始表面。基础色使用 sRGB；法线、金属度、粗糙度、AO 使用线性数据。说明法线贴图方向与通道约定；若采用 glTF ORM，R/G/B 分别为 AO/粗糙度/金属度。提供原始纹理及可用于网页的版本，逐项说明扫描、照片制作或人工制作来源。
- **来源与许可**：随资产交付清单，记录文件名、来源 URL 或提供方、作者/权利人、获取日期、许可证明、可否修改与公开网页再分发、署名要求和内容哈希。没有授权的第三方模型不纳入发布包。

| 功能组名称 | 内容与代表性细节 ID |
| --- | --- |
| `fan` | 风扇、进气、分流结构；`fan-blade` |
| `compressor` | 低压与高压压气机子组；`compressor-rotor` |
| `combustor` | 环形燃烧室、喷嘴、观察双轴的位置；`fuel-injector`、`drive-shafts` |
| `turbine` | 高压与低压涡轮、对应轴段；轴段可沿用 `drive-shafts` |
| `nozzle` | 核心排气喷管、尾锥及明确归属的出口结构；`exhaust-cone` |
| `accessories` | 附件、管路、线束与接头；`oil-line` |

六个细节需要关联真实节点，并提供 `featureId`、`parentPart` 和部件局部坐标 `anchor`。管路应标明系统用途、起点和终点；双轴需要标明所属转子及机械连接。节点命名与实际构型不一致时先记录映射，不依靠名称推断零件身份。

## 对照验收清单

1. 确认具体子型号、资产版本、授权范围及缺失部件；检查来源和模型是否属于同一构型。
2. 用已知尺寸验证单位、全局比例和主轴方向。约定整体尺寸、关键零件尺寸及轮廓误差阈值后，记录实际测量结果；没有基准的尺寸标为“未核验”。
3. 提供同构型的前、侧、后及关键局部照片或正投影视图，注明拍摄视角与已知量尺。分别核对进气外形、叶片/级数、机匣、双轴关系、燃烧室、外涵出口和管路连接；不要把透视照片当成无畸变工程量尺。
4. 对照叶片、金属机匣、热端、喷嘴和管路的近景，检查 UV、拉伸、硬边、贴图分辨率、粗糙度和法线方向。区分实物表面细节与人为烘焙阴影。
5. 验证合拢间隙、独立转子、剖面与逐件动画；保留真实结构和教学拆解的区别。最终列出通过项、误差、简化和仍未核验项，再决定是否可以使用“1:1”或“高保真还原”的表述。

满足上述输入与对照要求后，可继续复用现有相机、选取、部件姿态、细节热点与说明系统。官方网页用于核对与定位参考，不能替代待提供的几何、材质和授权资产。
