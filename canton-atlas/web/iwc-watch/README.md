# IWC · 时间的构造

使用 Three.js 制作的独立腕表互动研究作品。视觉参考为 IWC 葡萄牙系列自动腕表 40（IW358303），以 40.4 mm 表径、12.3 mm 厚度及 82200 型机芯为比例和结构参考。该页面不是 IWC 官方产品或授权展示。

## 本地运行

在工作区根目录执行：

```sh
npm run dev
```

打开 <http://127.0.0.1:4188/iwc-watch/>。页面使用 ES modules，需通过本地 HTTP 服务打开，不能直接双击 `index.html`。Three.js、OrbitControls、材质纹理和字体回退均在本地提供或在浏览器中生成，页面不依赖 CDN、远程模型下载或外部接口。浏览器须支持 WebGL 2，推荐启用硬件加速。

## 操作

- 拖动腕表旋转，滚轮缩放；触屏可用单指旋转、双指缩放。工具栏也提供缩放、自动旋转、重置和全屏。
- “经典 / 正面 / 背面 / 侧面”切换观察方向。“机芯探索”进入机芯观察状态。
- 点击“拆解探索”或调整“拆解进度”滑杆，查看组件的空间关系；“完整腕表”恢复装配。
- 点击模型上的部件，或在“零件图鉴”中搜索、按分类筛选并选择部件，查看结构与材质说明。
- 详情卡中的“分离部件”可单独移开选中部件，再次点击恢复；“单独查看”隐藏其他组件。“返回完整腕表”退出隔离。
- “重置视角与装配”恢复完整腕表和经典视角；“操作指南”“工艺档案”和“关于此模型”提供补充说明。

时针、分针及六点位置的小秒针都是独立三维几何。角度依据当前系统本地时间计算，包括毫秒对应的小秒针扫动，以及秒对分针、分钟对时针的连续贡献。系统时间改变时，显示时间随之校准。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` / `styles.css` | 中文界面、响应式布局、抽屉与说明弹窗 |
| `app.js` | 场景、光照、物理材质渲染、轨道控制、拾取、拆解和装配状态 |
| `watch-model.js` | 表壳、表镜、表盘、真实立体指针、表带等外观部件 |
| `movement.js` | 机芯主板、桥板、齿轮、自动陀、摆轮、游丝、螺丝和宝石轴承 |
| `vendor/` | 随项目提供的 Three.js 与 OrbitControls 依赖 |
| `../../../scripts/verify-iwc-watch.mjs` | 使用本机 Chrome 的浏览器交互验证脚本 |

蓝宝石表镜使用物理透射材质及接近蓝宝石的折射率，结合场景环境反射、表面粗糙度和厚度表现透明与折射。拉丝、日内瓦条纹、圆纹和皮革纹理按程序生成；多个部件共享可复用的几何和材质。渲染分辨率受控，以兼顾细节和交互成本。

## 验证

在工作区根目录运行：

```sh
node scripts/verify-iwc-watch.mjs
```

脚本默认使用 `C:\Program Files\Google\Chrome\Application\chrome.exe`，可通过 `IWC_CHROME_PATH` 环境变量修改。它启动临时本地预览，验证真实 WebGL 渲染、计时角度与连续运动、暂停和恢复、拖动和缩放、自动旋转、预设视角、直接点击拾取、部件拆解和复位、检索和隔离，以及桌面和触屏尺寸下的交互。移动测试通过 Chrome 原生触摸输入执行双指缩放，并检查手势结束不会误选零件。诊断报告和桌面、移动、拆解、机芯视图截图写入工作区的 `output/iwc-watch/`。

测试通过时可以确认这些交互在该次浏览器环境中可用；报告中的动画帧间隔是本次运行的观察值，不代表任何设备上的固定帧率保证。完整验证结果以实际生成的 `report.json` 为准。

2026-11-11 最终集成验证的 **14 项检查全部通过**，覆盖桌面 1440 × 1000 和移动 390 × 844 两种尺寸。模型有 114 个可检查部件、205 个网格及 322,052 个三角面；完全拆解时 113 个部件发生位移，固定基准件保留原位。蓝宝石材质折射率为 1.77，透射系数为 1。拆解动画进行中隔离小螺丝后，选中件位置漂移为零，保持在视口中心；截图和装配模式切换过程中，场景内部水平滚动偏移为零。该次运行没有浏览器异常、控制台错误、失败资源请求或外部网络请求。详细结果见 `output/iwc-watch/report.json`。

## 还原范围

模型依据公开外观和机芯结构特征进行程序化重建，保持系列识别特征及主要比例。它不包含厂商的专有 CAD、公差或完整维修资料，机芯局部布局、啮合和组件尺寸有视觉化简化；动画用于解释机械运动，不是可以用于制造、维修或动力学验证的精确机构仿真。完整独立选择范围以零件图鉴列出的组件为准，局部表面刻线与装饰几何属于对应组件。

渲染使用实时近似。表镜折射、金属高光与微观纹理随视角、显示器和 GPU 而变化，不能等同于离线路径追踪或实物摄影。模型不会模拟蓝宝石晶体的各向异性、双折射或完整光谱镀膜。移动设备和软件 WebGL 环境的运行速度也会低于具备硬件加速的桌面浏览器。
