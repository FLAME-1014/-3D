# 肖像 × WebGL 作品集

独立入口 `/portrait-portfolio/`，沿用工作区已有静态服务与本地 Three.js 0.179.1 模块。版式采用暖白、深绿和纸黄色，包含三维数字分身、项目作品、关于、演讲地球仪及合作入口。

**当前没有收到用户的肖像原图和真实演讲记录。** 林间、原创三维角色和六个活动均为示例，不代表某个真实人物，不声称已经完成真人肖像转换。肖像上传功能用于保存建模参考，不会自动重建人脸。拿到原图后，可继续在 Blender 中按相似度要求制作，导出 GLB 替换。

## 启动与验证

在仓库根目录运行：

```powershell
npm run dev:portfolio
```

打开 `http://127.0.0.1:4192/portrait-portfolio/`。已有服务也可直接访问这个路径。指定端口可设置 `PORT` 环境变量；不要结束不明来源的占用进程。

```powershell
npm run test:portfolio
npm run check
npm test
```

作品集验证脚本自动创建临时 HTTP 服务，默认使用系统 Chrome 和项目已安装的 Playwright。报告、桌面/移动端截图写到 `output/portrait-portfolio/`。完整项目是静态网页，无后端；必须通过 HTTP 打开，不能双击 HTML。

本轮验证（2026-11-11）：作品集 13 组浏览器检查通过，无未预期控制台错误、失败 HTTP 请求或外部请求；源码与 130 个 HTML 本地引用检查通过，原项目 41 项测试全部通过。另检查了 320px 窄屏，以及实际 WebGL 上下文在 GLB 加载中丢失的降级路径。浏览器验证使用桌面 Chrome 和模拟手机视口，未覆盖真实 iOS / Android 设备。

## 使用方式

- 角色可拖动旋转，工具栏支持自动旋转、线框、恢复视角和透明 PNG 视图下载。
- 地球使用真实大陆轮廓，支持自动旋转、拖动、点击活动标记；右侧活动按钮可用键盘操作，并按年份筛选。
- 「编辑作品集」可以编辑姓名、介绍、邮箱和活动（主题、城市、日期、经纬度、场地等）。点击「保存更改」才保存资料和路线，关闭面板会放弃未保存的这些字段。
- 上传肖像参考、替换 GLB、调整外套颜色和导入配置会即时生效，面板中有明确提示。
- 资料和参考图存入此来源的 `localStorage`；自定义 GLB 存入 `IndexedDB`，刷新后自动恢复。不同端口属于不同来源，数据不互通；没有上传至服务器或跨设备同步。
- 导出 JSON 包含已保存的个人资料、活动、外套配色和肖像参考图。**GLB 二进制不包含在配置中，需单独保留原文件。** 导入 JSON 会校验格式、日期、经纬度、唯一活动 ID 和数量，失败不会覆盖原内容。
- 联系邮箱默认空白；合作入口会引导填写邮箱。填写后打开用户邮件客户端，不自动发信。
- 系统开启「减少动态效果」时，自动旋转关闭，手动操作仍可用。视口外和后台标签页暂停绘制。WebGL 不可用时，角色显示透明海报，地球显示可点选的 SVG 地图。

## 模型制作与替换

实际生成脚本：`scripts/build_portfolio_character.py`。默认输出到本目录 `assets/`：

```powershell
& 'D:\blender.exe' --background --factory-startup --python-exit-code 1 --python scripts/build_portfolio_character.py
```

可用脚本的 `--output` 参数改输出目录（放在 Blender 的 `--` 后，详见脚本）。重新生成会覆盖该输出目录中的同名生成文件；精修工程请先另存副本。

- `character.blend`：可编辑网格、PBR 材质、灯光、相机。
- `character.glb`：网页角色，约 2.52 MB，130 个网格、19 材质、130,256 三角面；嵌入全部所需数据。
- `character-poster.png`：1200×1500 透明渲染图，也是 WebGL 降级海报。
- `model-info.json`：实际模型尺寸、统计及 `reference: "none"`、`likenessClaim: false`。

角色为风格化半身像，未绑定骨骼，不含面部表情或口型动画。Blender 正面为 -Y，导出 GLB 正面为 +Z、向上 +Y。网页会自动计算包围盒、居中并适配视角。网页材质换色匹配 `Clothing_Jacket` 和 `Clothing_Lapel`，自定义模型若无这些材质名则保留原材质。

自定义 GLB 最大 20 MB，须是 glTF 2.0 单文件，并嵌入图片和缓冲区；当前未加载 Draco、KTX2 或 Meshopt 解码器，替换时使用 Blender 的普通未压缩 GLB 导出。无有效网格或含外部图片依赖的文件会被拒绝。自定义模型的静态降级海报仍使用项目提供的示例海报，页面会提示静态预览；若发布新角色，应同步更新海报文件。

## 内容与网站资产

- `data.js`：默认资料、演讲和三个项目卡片，修改后重新加载未保存过的浏览器即可看到；已有浏览器保存值优先。
- `app.js`：编辑器、验证、持久化、活动联动与资产导入。
- `character-viewer.js`：GLB 加载、交互、材质与海报降级。
- `globe.js`：地球、活动坐标、弧线和 SVG 降级。
- `assets/asset-manifest.json`：封面来源、裁切记录、角色来源和地理数据许可。

三个项目分别链接工作区已有的广州立体志、AERIS 航空发动机、微缩东方页面；没有新增或改写它们的实现。封面总计约 276 KB。地球使用 Natural Earth 1:110m 公有领域数据，来源记录见 `assets/globe-land-source.txt`。已有项目素材的权属状态沿用工作区记录，未新增核实。

运行时不请求 CDN、外部字体或外部地理数据。Three.js 与加载器复用 `../blender-workflow/vendor/`，保留该目录的 MIT 许可证。将页面复制到其他站点时，需要一并保留该依赖目录、`assets/` 和相应项目页面，或修改引用路径。

页面和数据均未发布至公网。编辑器更改只保存在浏览器；正式更新静态站点时，应将核实后的资料写入 `data.js`，替换示例角色和海报，并更新 `demo` 字段。
