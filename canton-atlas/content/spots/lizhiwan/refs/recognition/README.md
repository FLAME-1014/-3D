# 3 秒识别测试 · 荔枝湾（B 级 lite）

> 目的：验证“没有文字提示时，模型截图能否在 3 秒内被认出是荔枝湾 / 西关水岸”。  
> 这是人工测试，不能用 AI 代替。  
> **B 级只做 1–2 人 lite；不需要 5 人。**

---

## 测试材料

优先使用：

- `../preview/preview-canal.png`（河涌 + 龙津桥 + 文塔 + 画舫）
- 或 `../preview/preview-overview.png`（河涌 + 两岸西关大屋 + 大戏台）
- 或 `../preview/preview-bridge.png`（龙津桥三拱）

不要把网页标题、面板文字、热点标签一起展示；只截取左侧 3D 画面，或把面板遮住。

---

## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：说出“荔枝湾 / 荔枝湾涌 / 西关水岸”，或能描述“一条河涌、两岸荔枝树、三拱石桥、文塔、西关大屋/满洲窗、画舫”等唯一特征。
