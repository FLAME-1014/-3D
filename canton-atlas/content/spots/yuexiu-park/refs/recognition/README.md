# 3 秒识别测试 · 越秀公园（B 级 lite）

> 目的：验证“没有文字提示时，模型截图能否在 3 秒内被认出是越秀公园 / 五羊石像”。  
> 这是人工测试，不能用 AI 代替。  
> **B 级只做 1–2 人 lite；不需要 5 人。**

---

## 测试材料

优先使用：

- `../preview/preview-wuyang.png`（五羊石像 + 岩座）
- 或 `../preview/preview-overview.png`（五羊 + 明城墙 + 镇海楼同框）
- 或 `../preview/preview-zhenhai.png`（五层镇海楼）

不要把网页标题、面板文字、热点标签一起展示；只截取左侧 3D 画面，或把面板遮住。

---

## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：说出“越秀公园 / 五羊 / 五羊石像 / 镇海楼”，或能描述“五只羊站在岩石上、明城墙、五层红墙绿瓦楼”等唯一特征。
