## 判定口径

**算正确：**

- 直接说出“广州大剧院 / 大剧院 / 广州歌剧院 / 双砾石 / 圆润双砾”。
- 或描述以下特征中的**至少 3 项**：
  1. 一黑一白 / 一大一小两块砾石；
  2. 两块石头都没有直角、三角折面；
  3. 大砾石南/东南的大玻璃口部（内部斜网格）；
  4. 5 m 入口平台 / 南侧缓坡 / 建筑在水池中；
  5. 三角形石材 + 三角形点支玻璃表皮；
  6. 花城广场西南角 / 珠江西路 / 省博与图书馆西侧。

**不算正确：**

- 只说“一个剧院 / 歌剧院 / 音乐厅 / 艺术中心”，没有“广州大剧院/双砾石”或 3 项特征。
- 说成“广东省博物馆 / 月光宝盒 / 广州图书馆 / 广州塔 / 海心沙 / 广州大剧院旧版城市模型”。
- 只根据展台、树阵、水池猜“公园/广场”。
