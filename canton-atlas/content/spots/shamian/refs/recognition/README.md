# 3 秒识别测试 · 沙面岛（B 级 lite）

> 目的：验证“没有文字提示时，模型截图能否在 3 秒内被认出是沙面 / 沙面岛”。  
> 这是人工测试，不能用 AI 代替。  
> **B 级只做 1–2 人 lite；不需要 5 人。**

---

## 测试材料

优先使用：

- `../preview/preview-overview.png`（岛体总览：欧陆建筑 + 教堂 + 白天鹅）
- 或 `../preview/preview-avenue.png`（林荫道）

不要展示网页标题、面板文字或任何带“沙面”的界面。

---

## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：说出“沙面 / 沙面岛”，或能描述“欧陆建筑、教堂尖塔、白天鹅、岛上林荫道、白鹅潭”等唯一特征。
