### 画面口径提醒

- 本模型是 **王墓展区**（解放北路 867 号），不是王宫展区（中山四路 316 号）。
- 石虎的位置按广州日报/广州市政府门户网站“临街正立面、入口台阶左右”的描述放在入口；维基百科另有“44 级蹬道尽头、墓室保护区门外”的写法，争议已在项目记录中注明。识别时以“南越王墓博物馆入口序列”整体判断，不要求测试者指认石虎精确位置。
- 模型是风格化场地段 diorama，不是 9,668㎡ 全展区 1:1，也不是墓室内部 1:1。

## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

建议先看 `test-overview.png`；如果对方需要第二张，再看 `test-gate.png`，不要一次把五张都摊开。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：

- 说出“南越王博物院”“南越王墓博物馆”“西汉南越王博物馆”或“王墓展区”；
- 或描述出“红砂岩正立面 + 中间一线天/半圆拱 + 山上的覆斗形玻璃墓室罩 + 玉圭门阙 + 石虎/越人浮雕”中的至少 3 项组合特征。

仅说“一个博物馆”“一个古墓”“广州的公园”不算；把王宫展区、广州博物馆、陈家祠等说成答案也不算。
