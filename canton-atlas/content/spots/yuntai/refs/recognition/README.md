## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：说出“云台花园”，或能描述“白云山南门的花园 / 白色罗马柱廊 / 中轴喷泉和阶梯水景 / 玻璃温室 / 玫瑰园花海”等组合特征。仅说“一个公园 / 有花”不算。
