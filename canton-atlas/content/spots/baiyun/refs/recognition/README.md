### 画面口径提醒

- 本模型是 **白云山摩星岭登顶段**，不是云台花园（白云山南麓），也不是白云山山顶广场/白云晚望。
- 模型是 120×90m 登顶段 diorama，不是 21.8 km² 白云山 1:1，也不是 382m 高差实测；台地、城市与珠江均为压缩示意。
- “锦绣南天”牌坊与山脚“摩星岭”石门是两座门，模型分开建模；不要把二者混为一座。
- 山顶亭在游记中有“摘斗亭/山顶亭”等不同叫法，模型只写“山顶观景亭”。

## 测试方法（B 级 lite）

1. 找 1–2 位没有参与项目的人。
2. 每人单独测试，不要互相讨论。
3. 给对方看截图 **3 秒**，然后关掉。
4. 问：“这是广州的哪个地方？说得出名字或特征都算。”
5. 记录回答；不要提示、不要追问、不要给选项。

建议先看 `test-overview.png`；如果对方需要第二张，再看 `test-summit.png` 或 `test-gate.png`，不要一次把五张都摊开。

---

## 通过线

- **2 人 2/2 通过**：B 级 lite 通过。
- **1/2 通过**：升级到 A 级 5 人。
- **0/2 通过**：直接 fail，先修模型。

“正确”包括：

- 说出“白云山摩星岭”“摩星岭”“白云山主峰”；
- 或描述出“山脚石门/竖匾摩星岭 + 陡石级 + 锦绣南天牌坊 + 西侧栈道/扶梯 + 星形指北碑/1900km 北京/海拔382米 + 白亭 + 南望广州塔”中的至少 3 项组合特征。

仅说“白云山”（不说摩星岭、也不描述 3 项特征）不算；把云台花园、山顶广场/白云晚望、广州塔、越秀公园等说成答案也不算。
