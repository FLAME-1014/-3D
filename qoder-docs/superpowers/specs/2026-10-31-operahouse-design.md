## 1. 目标

做一个可漫游的广州大剧院**纯外观** 1:1 近景：从南/东南前广场与水池看“一黑一白、一大一小”的双砾，走近大砾石的三角玻璃口部，绕到西侧珠江西路看封闭石背，再看小砾石/草坡/坡道，最后用航拍读文化轴与广州塔/省博/图书馆/花城广场的关系，并在夜景看“水映双砾”。三档时段（晴日/黄昏/夜景）、7 视点、7 热点、4K、移动端，接入图鉴 `opera-house` 与城市 POC `operahouse`。不做观众厅、舞台、后台、排练厅、餐厅、车库、内部导览。

## 2. 范围

### 包含

- 大砾石（深灰/近黑石材，43.1 m，约 120 m 最大长度，1,804 座歌剧厅的**外壳**）与小砾石（白/浅灰石材，约 28 m 高，实验剧场/多功能厅**外壳**），最近约 3 m。
- 双砾的三角折面外壳、三角形石材板缝、南/东南大三角玻璃口部、小砾石低长玻璃带、内部钢斜网格的浅层剪影（不做观众厅/舞台/后台）。
- **5 m 入口平台**、南入口缓坡/台阶、草坡、平台边缘狭缝/栏板、底层水池/倒影、前广场/树阵/灯柱/栏杆。
- 南/东南前广场（双砾全景）、西侧珠江西路（石背）、东侧小砾石/草坡/坡道；花城广场/省博/图书馆/IFC/CBD/珠江/海心沙/广州塔的压缩示意。
- 三档时段、7 视点、7 热点、开场运镜、4K 截图、移动端、考据面板、图鉴/城市互跳。
- 1 unit = 1 m；双砾主要体量、5 m 平台、前广场/水池/草坡（按公开描述 + 卫星/照片估算）1:1；周边城市压缩并标注。

### 不包含

- 观众厅内部、舞台、后台、台仓、排练厅、录音棚、餐厅、售票中心、咖啡厅、车库、地下落客区、设备用房。
- 1,804 个座位、满天星天花、舞台机械、声学构造的室内建模；只在热点/考据里讲。
- 5,000+/75,000 块玻璃/石材的逐块建模；用程序化三角形板缝/玻璃网格纹理 + 主口部可数 3D 斜网格。
- 测绘级城市、真实地形、实时 POI/高德、车流/人流/游船、演出活动、每日/节日灯光节目单。
- 省博/图书馆/IFC/CBD/广州塔的细节；只做体量/剪影/窗光；省博另有独立近景。
- 城市 POC 现有压缩双球模型的替换/共享几何；近景与 POC 独立，POC 保留现状。

## 3. 体验与交互

### 3.1 开场运镜

- 约 36–40 s：从珠江/海心沙上空看广州塔与中轴 → 沿江向北到花城广场/双砾南侧 → 贴近水池/草坡 → 绕大砾石玻璃口部 → 升到航拍看双砾与文化轴 → 收在南广场夜景（末段自动切夜景）。
- 支持「跳过运镜」；`embed=1` 自动跳过；`prefers-reduced-motion` 直接进入 `plaza`。
- 相机路径不穿双砾：距大砾石外壳 ≥ 18 m（玻璃口部近景 ≥ 12 m），距小砾石 ≥ 12 m；切换用平滑阻尼。
- 运镜末段从 `axis` 高空下到 `night` 时用 0.8 s 淡入/快速下移，不穿建筑。

### 3.5 三档时段

- 内部名固定 `day` / `dusk` / `night`；UI 文案「晴日」「黄昏」「夜景」；按钮循环 day → dusk → night → day。
- 晴日：高能见度；大砾石深灰/近黑石面、小砾石白/浅灰；玻璃蓝灰反射天空；草坡饱和绿；水池深青；太阳东南侧光；石面三角板缝清楚。
- 黄昏：低角度暖光；大砾石暖灰/青铜调、小砾石米白；玻璃反金/紫；水池反射天空；玻璃口部内透开始亮；平台/草坡水纹光带 30–50%；适合 `plaza`/`pool`/`axis`。
- 夜景：深蓝黑天空 + 星点/薄云；大砾石深灰近黑 + 根部暖白淡投光；玻璃口部内透暖白/中性，钢斜网格成剪影；小砾石白面呈暖灰；平台/草坡挡墙的暖白“水纹”光带；水池镜面倒影；CBD 窗光冷/暖混合；`night` 强制此档。
- 夜景色板（示意，不做 RGB 秀）：
  - 石面基座：2700–3000 K 暖白，向上快速衰减。
  - 玻璃口部内透：3500–4000 K 中性偏暖。
  - 水纹光带：2700–3000 K 暖白，低亮度、连续、蜿蜒。
  - 天空/城市：深蓝灰 + 冷白/暖黄窗光。
- 官方色温/灯具清单未公开；页面标注「色温/亮度为参考图观察与示意，不是官方值」。
- 不做逐灯、不做 RGB 渐变、不做激光、不做每日/节日节目单。

### 3.6 移动端

- 390×844，DPR 上限 1.35（实测 60fps 后可试 1.5），fov +4；视点栏横向滚动；热点卡片底部抽屉；信息卡可滚动。
- 城市块/树/斜网格杆件减量；阴影关闭；水面反射降级；玻璃口部保留主斜网格，小砾石玻璃带用纹理。
- 目标 60fps；无横向溢出；触控目标 ≥ 44 px；intro 可跳过。
- 4K 按钮提示「建议桌面」；`axis` 航拍视点在移动端保持全屏宽高比，不裁掉广州塔剪影。

## 4. 场景构成

### 4.1 坐标与 1:1 边界

- 1 unit = 1 m；+X 东、+Z 南、+Y 上；地面/广场 y=0；原点在南/东南前广场与水池之间；大砾石中心 (-35,0,-55)，小砾石中心 (+45,0,-60)；入口平台 +5 m。
- 1:1/近似 1:1：大砾石 120 m 最大长度 × 约 85 m 宽 × 43.1 m 高；小砾石约 65 × 45 × 28 m（高为估算）；约 3 m 间距；5 m 入口平台；前广场/水池/草坡/缓坡（尺寸按公开描述 + 卫星/照片估算，页面标注「估算」）；近景树阵。
- 示意/压缩：双砾精确折面/棱线、玻璃/石材逐块、水池/喷泉/铺装细节、草坡/坡道精确尺寸、省博/图书馆体量细节、IFC/CBD/广州塔/珠江/海心沙距离与体量、夜景色温/亮度。
- 城市压缩：近景 300 m 内（双砾、前广场、树阵、省博/图书馆的大致方位）按近似真实；300 m 外（IFC/CBD/广州塔/珠江对岸）按约 0.6–0.7× 距离压缩 + 雾；页面标注「周边城市压缩示意，非测绘」。
- 所有页面（intro/about/footer）标注：「纯外观；双砾/5 m 平台/前广场按公开资料与卫星照片 1:1 估算；周边城市压缩示意；内部/舞台/后台不做；夜景为‘水映双砾’示意，不是实时灯光秀；非测绘。」

### 4.2 双砾石

- 大砾石：位于西/西南，深灰/近黑花岗岩；长轴大致西北—东南；最大长度约 120 m、宽约 85 m、高 43.1 m；南/东南面是大三角玻璃口部；屋顶与墙面连续，顶部折成若干大三角面；底部有低矮基座/设备口；西/北面以封闭石面为主，只有少量狭长玻璃缝。
- 小砾石：位于东/东北，白/浅灰石材；长约 65 m、宽约 45 m、高约 28 m（估算）；南/东面是较低、较长的玻璃带；屋顶更低更圆润；与草坡相连。
- 两体最近约 3 m；大、小砾石之间是入口平台/缝隙，不做内部连接体。
- 外壳是**非几何折面**：没有垂直墙、没有标准立面、几乎找不到直角；不要做成两个规则椭球/光滑球体。低模也要保留“大三角折面”的硬边/平面感（flat shading）。
- 石面：大砾石深灰/近黑，小砾石白/浅白；石面有三角形板缝、轻微雨痕/风化；不做“崭新展台”或过度脏污。

### 4.3 外壳、玻璃口部与表皮

- 外壳逻辑：三向斜交折板式单层网壳；大砾石 64 个空间折面、104 条棱线、41 个角点（小砾石 37/54/18）；场景用 8–12 圈 × 16–24 点的折面壳近似，保留 40–80 个大三角面；不逐面/逐棱复刻。
- 石面：三角形石材分片（约 2–5 m 级）；程序化三角形板缝 + 轻微 bump/normal；深/浅两套石材；开放式石材幕墙的四层构造只在考据里讲，不做剖面。
- 玻璃口部（大砾石）：南/东南的大三角玻璃面，凹在石折檐下；玻璃后是浅层 lobby 剪影（暗色地面/顶面 + 2–3 片钢构件/斜柱 + 暖光），**不做观众厅/舞台/座位**；玻璃前有可数的 3D 斜网格杆件（约 1.5–2.5 m 级），其余玻璃带用纹理网格。
- 玻璃带（小砾石）：南/东的低长玻璃带；用玻璃材质 + 三角形斜网格纹理；可选少量 3D 杆件；夜间透暖光。
- 玻璃材质：三角形点支玻璃的感觉；透明/半透明、菲涅尔天空反射、轻微蓝灰；夜间内部暖光；不做逐块玻璃、不做镜面实时反射。
- 石折檐/屋顶：入口玻璃口部上方有石面折檐/挑出；屋顶与墙面连续，不做独立屋檐/女儿墙；顶部可做少量低矮通风口/擦窗设施（不显眼）。
- 板缝/网格密度：石面大三角（2–5 m）、玻璃口部密三角（1.5–2.5 m）；不要矩形幕墙或均匀方格。

### 4.4 入口平台、草坡、水池与坡道

- 入口平台：+5 m；南入口是主入口；观众从室外缓坡/台阶上到平台；平台是双砾共用的室外门厅；平台边缘有狭缝/栏板；不做室内门厅。
- 缓坡/台阶：南侧缓坡（约 1:12，宽 4–6 m，估算）+ 局部台阶；细金属栏杆；与草坡衔接；不做无障碍电梯。
- 草坡：南/东南/西侧的高草缓坡，从广场 0 m 升到平台 5 m；草坡是“山丘”的视觉主体；草坡下是咖啡/售票/研究空间（不做室内），只做挡墙/暗色开口/光带示意；草坡上可少量步道/坐凳（简化）。

### 6.2 双砾几何与 draw calls

实现方式：

- **折面壳**：每块砾石用 8–12 圈水平环 × 16–24 个点，按半径/偏心/高度变化生成折面 `BufferGeometry`；`flatShading: true`；大砾石保留 43.1 m 高、约 120 m 长；小砾石约 28 m 高；两体最近 3 m；所有折面共享深/浅两套石材材质（各 1 draw call）。
- **玻璃口部**：大砾石南/东南面单独切出玻璃面（或叠加在石面开口上），用 2–3 片折面玻璃 + 内部浅层 lobby（暗色地面/顶面 + 2–3 片钢构件 + 暖光平面）；玻璃材质透明/菲涅尔；2–3 draw calls。
- **斜网格**：大砾石玻璃口部的三角斜网格用 `InstancedMesh` 细杆（约 120–240 根，4 边/1 段）或手工合并 `BufferGeometry`；1–2 draw calls；小砾石玻璃带用纹理，不逐杆。
- **石面细节**：三角形板缝用程序化纹理 + bump/normal；不逐块石材；深/浅两套石材 + 1 套玻璃网格纹理。
- **平台/草坡/水池/坡道**：平台用不规则多边形挤出；草坡用带高度的网格；水池用平面 + 池底；坡道/台阶用低模；合并为 6–10 draw calls。
- **树/草**：InstancedMesh；2–3 种树 + 草簇；桌面 150–250 棵、移动 80–120 棵。
- **城市**：省博/图书馆/IFC/CBD/广州塔用低模体量 + 实例化窗光/LineSegments；不做每栋细节。

预算（桌面 LOD0）：

| 部件 | 方法 | draw calls | triangles（约） |
|---|---|---:|---:|
| 双砾石壳（深/浅） | 折面 BufferGeometry + flatShading | 2 | 4,000–6,000 |
| 玻璃口部/玻璃带/浅层 lobby | 透明玻璃 + 内部剪影 | 3–4 | 2,500–4,000 |
| 大砾石斜网格 | InstancedMesh/合并杆 | 1 | 5,000–8,000 |
| 平台/草坡/坡道/台阶/栏板 | 合并/低模 | 8 | 5,000–7,000 |
| 水池/池底/水 shader/可选喷泉 | 平面 + shader/粒子 | 4 | 2,000–3,000 |
| 树/草/灯柱/坐凳/栏杆 | InstancedMesh + 合并 | 6 | 12,000–18,000 |
| 城市（省博/图书馆/IFC/CBD/广州塔/珠江/海心沙） | 低模 + 实例化/线框 | 12–16 | 25,000–40,000 |
| 天空/星/云/glow | Shader/Sprite/Points | 4 | ~1,000 |
| **合计（目标）** | | **~45–60** | **~60k–85k** |

- 移动端 LOD1：树 80–120、城市块/窗光减半、斜网格 60–70%、玻璃带纹理化、阴影关闭；双砾壳折面数降低但保留大三角硬边；目标 ≤ 80 calls / 80k tris。
- 预算：桌面 1440×900 **draw calls ≤ 120、triangles ≤ 140k、textures ≤ 20、lights ≤ 5**；移动 390×844 **draw calls ≤ 80、triangles ≤ 80k、DPR ≤ 1.35、shadows off**。
- 不启用后处理（bloom/SSAO/DOF）；用 emissive、Sprite、Points 做光晕；水不做实时平面反射。

### 6.3 全场景预算

- 桌面：calls ≤ 120、tris ≤ 140k；固定视点 60fps；切换瞬态 ≥ 50fps。
- 移动：calls ≤ 80、tris ≤ 80k；固定视点 60fps；无横向溢出。
- 纹理 ≤ 20；光源 ≤ 5（太阳/月亮 + 半球 + 环境 + 1–2 点光）；阴影 1024/2048 仅桌面、仅近景，夜间关闭。
- 远景（> 300 m）雾化/压缩；城市/广州塔不投实时阴影；水体/玻璃不逐块。

### 6.4 材质与纹理

- 大砾石石材：深灰/近黑 `#3b3e3f`，roughness 0.82–0.9，metalness 0.05；三角形板缝 + 轻微雨痕/风化；bump/normal。
- 小砾石石材：暖白/浅灰 `#d8d4c8`，roughness 0.8，metalness 0.05；三角形板缝 + 轻微污渍；bump/normal。
- 玻璃：蓝灰 `#6f8794`，透明 0.25–0.4，roughness 0.12–0.18；菲涅尔天空反射；夜间内透暖光；不做逐块。
- 斜网格：深灰/黑金属 `#2a2d2e`，roughness 0.5，metalness 0.6；夜间受内部暖光/轻微 emissive。
- 铺装：浅灰/暖灰花岗岩 + 细缝；草坡：绿色斑驳 + 高草纹理；水：深青灰 + 细波纹；树：低模树冠/树皮；城市：暗底 + 暖/冷窗光；水纹光带：暖白渐变 + 波浪；glow：径向渐变。
- 签名墙（可选）：金属灰底 + “广州大剧院 / Guangzhou Opera House” 文字 canvas；放在南/西侧，参考图；不进入图鉴资源。
- 所有纹理程序化；不下载/不使用版权贴图；参考图只做观察。

### 6.5 夜间 shader 与灯光

- 共享 `ShaderMaterial`/材质 uniform：`uMode`（0 day / 1 dusk / 2 night）、`uTime`、`uGlow`、`uRipple`、`uBottomWarm`、`uInteriorWarm`。
- 石面：在 `MeshStandardMaterial` 上叠加底部暖光渐变（世界 Y 低于 8–12 m 暖白，向上衰减）；夜间保留石面纹理/板缝；不做通体发光。
- 玻璃口部：玻璃 shader = 菲涅尔天空反射 + 内部暖光透射 + 斜网格剪影；夜间 `uInteriorWarm` 提高；白天反射天空/城市。
- 水纹光带：沿平台栏板/草坡挡墙的 emissive 条带，使用波浪纹理 + `uTime` 缓慢流动；夜间 2700–3000 K；不做逐灯。
- 水池：假倒影/水 shader：深色底 + 玻璃暖光/光带的竖向拖影 + 细波纹；不做实时平面反射。
- 城市窗光：canvas 纹理 + Points/Sprite；夜间亮，白天压暗；广州塔用低模线框/窗光，不做逐灯。
- 灯光：day 1 太阳方向光 + 1 半球 + 环境；dusk 低角度暖光；night 1 月光方向 + 1 环境 + 1–2 暖色点光（入口/水池）；不做后处理。
- 阴影：双砾/平台/树 1024/2048，桌面；移动/夜间关闭。

### 6.6 相机/渲染/调试 API

- 渲染：WebGLRenderer + ACESFilmicToneMapping + sRGB；`setPixelRatio(min(dpr, mobile?1.35:1.85))`；fog；无后处理。
- 相机：PerspectiveCamera；桌面 fov 55、移动 62（视点 +4）；近 0.3 m、远 5000 m；视点切换阻尼 1.4–2.0 s。
- Debug API `window.OperaHouseDebug`：
  - getters：`fps`, `mode`, `view`, `time`, `renderer`, `scene`, `camera`, `model`, `counts`, `shell`。
  - `counts`：`{calls, triangles, textures, geometries}`。
  - `shell`：`{pebbles:2, large:{length:120,height:43.1,faces:64,ridges:104,corners:41}, small:{length:65,height:28,faces:37,ridges:54,corners:18}, gap:3, glass:5200, stone:75422, drawCalls:...}`。
  - methods：`go(name)`, `look(pos,target)`, `timeOfDay(name)`, `open(id)`, `shot4K()`。
- 4K：`renderer.setPixelRatio(1); setSize(3840,2160,false)`；渲染一帧；`canvas.toBlob` PNG；恢复尺寸/DPR；移动端 toast 建议桌面。
- 性能采样：每 900 ms 计算 fps；CDP 验收读取 `OperaHouseDebug.fps/counts/shell`。

## 9. 关键取舍（2 个 A 范围内）

### 取舍 1：双砾曲面/表皮精度 vs 城市环境范围（推荐：双砾与广场优先，城市压缩）

- 选择：双砾主要体量、玻璃口部/斜网格、5 m 平台、前广场/水池/草坡做足；省博/图书馆只做体量，IFC/CBD/广州塔/珠江压缩 + 雾。
- 理由：广州大剧院的不可替代性是“两块非几何折面砾石 + 一黑一白 + 三角玻璃口部 + 5 m 平台/水池/草坡”，不是把珠江新城按测绘做一遍；43.1 m 的建筑需要近景细节，城市全 1:1 会稀释主体精度并把场景拉到 2–3 km。
- 代价：`axis` 航拍的城市距离/体量不是实测；页面必须标注「周边城市压缩示意」。缓解：保持轴线关系（广州塔—海心沙—花城广场—双砾/省博/图书馆—双塔—中信）、相对高度（广州塔 600 m、IFC 438.6 m、东塔 530 m、中信 391 m）、近景 1:1 锚定比例。

### 取舍 2：双砾石内部可见性 vs 外壳完整性（推荐：外壳完整 + 玻璃口部浅层剪影，不做剖面/内部）

- 选择：保留完整外壳；只通过玻璃口部看到浅层 lobby 剪影（暗色地面/顶面 + 2–3 片钢构件 + 暖光），不做观众厅/舞台/后台/座位，不做剖切/掀顶。
- 理由：A 范围明确“只做外观”；完整外壳是“砾石”识别的前提，剖切会破坏形体；1,804 座观众厅/舞台是内部信息，用热点/考据讲即可，建模成本高且与外观定位冲突。
- 代价：不能“走进”歌剧厅/舞台；页面必须写「内部/舞台/后台不做；玻璃口部后为浅层剪影」。缓解：把玻璃口部的斜网格/玻璃反射/暖光/水池倒影做足，让“透过去看”的感觉成立；热点 `stage` 用数字讲清 1,804/74×46/18×12。

### 附带决策：夜景用“水映双砾”暖白，不做 RGB 秀

- 选择：基座暖白淡投光 + 玻璃口部内透 + 平台/草坡水纹光带 + 池面倒影；3 档时段；夜间 2700–4000 K 示意；不做 RGB/激光/逐灯。
- 理由：真实照明主题是“水映双砾”，照片也呈现暖白/克制的层次；RGB 秀会与广州塔/其他地标混淆，也不符合公开资料。
- 代价：不是“灯光秀”；页面标注「色温/亮度为示意，不是官方值/实时节目」。
