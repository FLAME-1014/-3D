## 1. 目标

做一个可漫游的广东省博物馆（新馆）纯外观 1:1 近景：从花城广场西侧正面看「月光宝盒」，经西门台阶进入悬浮盒体下方的玻璃大堂，绕到西南角看四边 23 m 悬挑与红色切口，近看约 1.5 m 模数的深灰铝板与红色凹龛，再俯瞰方形「回」字屋面与约 40 m 中央天窗，最后以夜景红光收束。三档时段（晴日/黄昏/夜景）、7 视点、7 热点、4K、移动端；接入图鉴 `gd-museum` 深链与城市全景通用返回；**不新建城市 POC 点位**；不做展厅/内部。

## 2. 范围

### 包含

- 盒体：约 **113.5 m × 113.5 m** 见方、约 **44.5 m** 高的方形「回」字体量；**67.5 m** 见方核心筒；四边各 **23 m** 悬挑；底层 67.5 m 见方退进玻璃大堂；盒体底约 **+9 m**；中央约 **40 m** 天窗/中庭，顶约 **+38 m**。
- 立面：深灰/黑灰铝板、玻璃、花岗石；大块矩形洞口/凹龛/窗洞；鲜红内壁；竖向金属格栅；锯齿状顶边；白色「广东省博物馆」字牌；西/南立面为主，东/北立面同一系统但细节降低。
- 入口广场：西门散客入口、二层主入口、宽台阶/缓坡、两侧草坡、波浪石径/「月光宝盒下的丝绸」景观、树阵/灌木/花境；不做水池（公开资料/照片未见西门大型水池）。
- 城市关系（压缩示意）：西侧广州大剧院、广州市第二少年宫、花城广场中轴；北侧广州图书馆；南侧临江大道、珠江、海心沙、广州塔；东侧珠江东路与珠江新城东侧高层；北侧 CBD 双塔/CITIC 剪影。
- 7 视点、7 热点、三档时段、开场运镜、4K 截图、移动端、考据面板、图鉴深链、城市全景通用返回。
- 1 unit = 1 m；盒体/核心/悬挑/入口广场主要尺度 1:1；周边距离/体量压缩并标注。

### 不包含

- 展厅、展柜、文物、内部中庭/回廊、电梯、办公、安检流程、停车库内部。
- 中央天窗以下的中庭内部；只做屋顶玻璃天窗与环形屋面。
- 逐洞复刻立面（无公开立面图）；约 100–120 个洞口为**按照片的确定性设计**，不是测绘。
- 精细城市（逐栋楼、真实道路/车流/人流/游船）；只做 6–8 个地标 + 实例化城市块 + 雾。
- 逐灯夜景/灯光秀/每日节目单；夜景用 emissive + 少量点光，标注示意。
- 广州塔的高精度模型；只做低模剪影/色带，独立于广州塔近景。
- 城市 POC 现有压缩博物馆体量的替换/共享几何；两者独立。

## 3. 体验与交互

### 3.1 开场运镜

- 约 31 s：西南低空看盒体 → 沿广场转到西门正面 → 西门台阶/悬浮底层 → 西南角悬挑 → 表皮近观 → 屋顶「回」字/中央天窗 → 夜景红光。
- 支持「跳过运镜」；`embed=1` 自动跳过；`prefers-reduced-motion` 直接进入 `west` 视点。
- 运镜不穿盒体：路径保持在盒体外侧 ≥ 20 m；屋顶段在 y≥70 m；切换用阻尼 1.6–2.2 s。
- 运镜末段自动切夜景；重播时从当前时段回到晴日再开始（或保持用户时段，末段强制夜景后恢复？——固定为末段夜景，结束停在 `night`；用户可手动切回）。

### 3.5 三档时段

- 内部名固定 `day` / `dusk` / `night`；UI 文案「晴日」「黄昏」「夜景」；按钮循环 day → dusk → night → day；`night` 视点强制夜景。
- **晴日**：高能见度；深灰石墨铝板在阳光下偏浅灰；红内壁高饱和；玻璃深色映天；草坡绿；广州塔/图书馆/大剧院清晰；太阳西南侧光。
- **黄昏**：低角度暖光；金属转暖灰；红内壁更深；城市窗光约 30–50%；大堂/广场灯渐亮；天空橙紫；适合 `axis`。
- **夜景**：近黑天空 + 稀疏星点；外壳近黑；**红色内壁/切口 emissive**（主视觉）；大堂 2700–3000 K 暖光；广场 3000 K；少量窗光 5000–6000 K；城市窗光；广州塔低模色带；**不做整面泛光/激光/节目单**。
- 夜景色板（示意）：
  - 红内壁：`#ff3126`（高饱和）/ `#ff5a2e`（橙红）/ `#8e1418`（暗部）
  - 暖大堂：`#ffc27a` → `#ffd9a8`
  - 冷窗：`#a8d8ff`
  - 城市：暖 `#ffd49a`、冷 `#bfe6ff`
- 时段切换用 0.6–0.9 s 插值，避免材质闪烁；emissive 强度/颜色随时间过渡。

## 4. 场景构成

### 4.1 坐标与 1:1 边界

- 1 unit = 1 m；盒体中心 (0,0,0)；+Z 南、-Z 北、+X 东、-X 西；西广场 y=0。
- 盒体：x/z ∈ [-56.75, +56.75]；y ∈ [9, 44.5]；核心筒 x/z ∈ [-33.75, +33.75]；底层玻璃大堂 y ∈ [3, 9]；入口平台 y=3；中央天窗 40×40，y=38；屋顶 44.5。
- 1:1：盒体/核心/四边 23 m 悬挑/底层大堂/入口台阶主要尺度/字牌位置/西广场。
- 示意/估算：立面洞口位置/数量/深度、1.5 m 分格、中央天窗 40 m、入口抬升 3 m、草坡/台阶宽度、树阵/花境、城市距离/体量、塔剪影、夜景色温。
- 城市压缩：盒体/西广场/南侧草坡 1:1；广州塔真实约 1.2 km，位于省博**南偏西**，场景约 0.75× 压缩至 x≈-100、z≈+900；北侧 CBD 在 z≤-400 后压缩 0.7×；页面标注「周边压缩示意，非测绘」。

### 4.2 盒体、核心与悬挑

- 盒体：113.5 × 113.5 × 35.5 m（y 9→44.5），方形环；外墙厚 0.35 m；外圈金属立面 + 顶部锯齿；中央 40×40 m 天窗井。
- 核心筒/底层大堂：67.5 × 67.5 m，y 3→9；玻璃幕墙 + 深色竖梃；西门门洞宽约 18 m、高约 5.5 m；盒体四边各悬挑 23 m；底面为深色 soffit。
- 结构表达：不建内部桁架；用盒体底/顶厚度、核心筒退进、四边悬挑、屋顶环与热点图文表达「67.5 m 核心 + 23 m 悬挑 + 8700 t 悬挂」。可选在 About 用 SVG 剖面说明。
- 盒体底边：西侧入口上方留 30 m 宽 × 6 m 高的底部缺口（金属皮切口，露出玻璃大堂/soffit）；四角/其他边留 2–3 个底部缺口，强化漂浮。
- 顶部：外圈屋面 44.5 m；中央天窗 38 m；天窗井壁 6.5 m 深，内壁可红；屋顶边缘按顶部缺口形成锯齿；红色鳍片/内壁沿边缘点缀。

### 4.3 立面切口与表皮

- 模数：名义 1.5 m；每面 76 列 × 24 排（实际 113.5/76=1.493 m，35.5/24=1.479 m）；端部收边；金属板 UV 按 1.5 m 重复。
- 洞口族（确定性生成 + 手工 hero 洞）：
  - 每面约 24–32 个洞口；四面合计约 100–120（估算）。
  - 宽 2–10 个模数（约 3–15 m）；高 2–6 个模数（约 3–9 m）；深度 0.6–2.4 m。
  - 类型：约 40% 玻璃窗（深色玻璃 + 竖向格栅）、约 45% 红内壁凹龛、约 15% 深洞/暗部。
  - 顶部缺口：每面 3–6 处，深 1–3 个模数（约 1.5–4.5 m），形成锯齿顶边；屋顶轮廓跟随。
  - 西门 hero：入口上方底部缺口（约 30×6 m）；字牌实板区（约 20×4 m，y≈23，z≈+10）；字牌上方/两侧布置大洞口；避免洞口穿过字牌。
  - L 形/竖槽：每面 1–2 组，由 2–3 个相邻矩形组成，增加「象牙球透雕」层次。
- 构造：
  - 金属外皮：合并的墙面 BufferGeometry（按洞口切出网格），1 个材质/1–2 draw calls；板缝由程序纹理表达，不做每条缝几何。
  - 洞口：每个洞口 5 个面（左右/上/下/内背），凹龛内壁为红；玻璃窗背面为玻璃 + 竖梃；深洞背面为暗色。红内壁合并为 1 个材质/1 draw call；玻璃按暖/冷/暗 3 类合并；竖梃/格栅合并或 InstancedMesh。
  - 字牌：浅灰底板 + 黑字 canvas 纹理；不建官方 LOGO。
- 白天/夜间材质：
  - 金属：`#4b5053`，metalness 0.35，roughness 0.5；阳光下可偏浅灰；夜间 `#141619`。
  - 红内壁：`#a51f26` 白天；夜间 emissive `#ff3126`，强度 1.6–2.0；暗部 `#8e1418`。
  - 玻璃：`#1b262c`，metalness 0.35，roughness 0.18；夜间暖 `#ffc27a` / 冷 `#a8d8ff`，部分暗。
  - 花岗石/铺装：浅灰 `#8b8d8a`；草坡 `#5b7247`；soffit `#111315`；字牌底 `#d9d6cd`。

### 4.4 屋顶与中央天窗

- 环形屋面：外 113.5×113.5，内 40×40；板厚 0.6 m；深灰屋面/砾石质感；外缘锯齿；红色鳍片约 24–32 处（沿顶边/洞口内壁）。
- 中央天窗：40×40 m 玻璃面，y=38；微绿/深灰玻璃；分格约 2×2 m；下方不建中庭；天窗井壁 38→44.5 m，内壁灰/红；从 `roof` 视点可见「回」字与天窗低于屋面。
- 屋面设备：3–5 个低模设备箱/天窗洞口，简化；不做擦窗机/栏杆细部。

### 6.2 几何与 draw calls

实现方式：

- 盒体墙面：四个立面各自按 76×24 模数生成墙面四边形；洞口区域内不生成墙面，改为 5 面凹龛/窗盒；所有墙面合并为 1 个 BufferGeometry（金属材质）。
- 洞口族：`makeCuts(side, seed)` 确定性生成 + hero 洞（西门入口、字牌实板区、L 形槽、顶部缺口）；洞口数量桌面约 100–120，移动约 80–95（西门保持完整）。
- 红内壁：所有凹龛的 jamb/head/sill/back 合并为 1 个几何（红漆材质）；夜间统一 emissive。
- 玻璃窗：按暖/冷/暗 3 类合并；竖梃/格栅用 InstancedMesh 或合并薄盒；玻璃用不透明深色材质 + emissive 背面，避免透明排序。
- 核心筒/底层大堂：67.5×67.5 玻璃盒（y 3–9）+ 深色竖梃 + 门洞 + soffit；合并为 3–4 个 draw calls。
- 屋顶：外环 + 中央洞的 `THREE.Shape` + `ExtrudeGeometry`（0.6 m）；中央天窗玻璃 + 井壁；红色鳍片合并；设备箱低模。
- 广场：铺装平面 + 台阶/缓坡盒体合并 + 草坡/花池；树/棕榈用 InstancedMesh（树干/树冠分开）；波浪石径用 `CatmullRomCurve3` 带状几何。
- 城市：图书馆/大剧院/少年宫/广州塔为低模组合；东侧/北侧高层用 InstancedMesh + 共享窗光纹理；广州塔低模（约 3k tris）。
- 不依赖 `BufferGeometryUtils`；手工合并/实例化；不逐块建模幕墙板。

预算（桌面 LOD0，估算）：

- 不启用后处理（bloom/SSAO/DOF）；用 emissive、Sprite、Points 做光晕；水不做实时反射。

### 6.4 材质与纹理

- 金属板：程序化 512×512 canvas；底色 `#4b5053`；1.5 m 板缝（约每 64 px）；细噪点/拉丝； roughness 0.5、metalness 0.35；白天/黄昏/夜景通过 material.color/emissiveIntensity 调整。
- 红漆内壁：256×256；`#a51f26`；轻微刷痕/粗糙度变化；夜间 emissive `#ff3126`，强度 1.6–2.0；部分暗红 `#8e1418`。
- 玻璃：512×512；深蓝灰 `#1b262c`；暗框/反光条；用不透明材质，避免透明排序；夜间按暖/冷分类 emissive。
- 花岗石/铺装：512×512；1.5 m 灰石板 + 接缝 + 轻微色差；roughness 0.9。
- 草地：256×256 绿色噪声/短草；roughness 1；树冠用叶片纹理/顶点色，不做每片叶。
- 树皮/棕榈：128×256；棕榈干环纹；树冠低模。
- 城市窗光：256×512；暖/冷窗格；夜间 emissiveMap；东/北塔楼共享。
- 字牌：1024×256 canvas；浅灰底 + 黑字「广东省博物馆」；`makeSign()` 返回纹理与比例；不画 LOGO。
- 屋面：256×256 砾石/灰色；天窗玻璃微绿。
- glow：径向渐变 Sprite；用于大堂/广场/塔顶光晕。
- 所有纹理程序化；不下载/不使用版权贴图；参考图只做观察。

### 6.5 夜景与材质状态

- 不用逐灯/后处理；用 `MeshStandardMaterial.emissive` + 少量点光 + Sprite：
  - 红内壁：统一材质，`emissive=#ff3126`，强度 night 1.8 / dusk 0.35 / day 0.02；暗部用第二个红色材质 `#8e1418`（可选）。
  - 玻璃窗：暖 `#ffc27a`、冷 `#a8d8ff`、暗 `#0c1115` 三类；night 强度 0.8/0.6/0；dusk 0.25/0.15/0；day 0。
  - 大堂：暖色玻璃 + 2 个点光（2700–3000 K）+ 室内发光面；night 强度 1.0。
  - 广场：4–6 个低模灯柱 + 暖光 Sprite/点光；night 0.6。
  - 城市：窗光纹理 emissive；广州塔低模色带（青/金/紫，示意）；不做灯光秀。
  - 顶边红鳍：与红内壁同材质；night 更亮，形成"裂缝"轮廓。
- 时段插值：0.6–0.9 s；材质颜色/强度/雾/天空/曝光同步；避免夜间红色过曝（ACES + 曝光 1.0–1.1；必要时 clamp emissiveIntensity）。
- 不默认 bloom；光晕用 Sprite；不默认激光；不做每日节目。

- Debug API `window.GdMuseumDebug`：

## 9. 关键取舍（2 个 A 范围内）

### 取舍 1：镂空表皮精度 vs 城市环境范围（推荐：表皮优先，城市压缩）

- 选择：西门/南面立面做完整洞口族（约 100–120 个，含红内壁/玻璃/格栅/顶部缺口）；东/北面同系统但细节降低；城市只做 6–8 个地标 + 实例化城市块 + 雾，广州塔低模，距离压缩 0.7–0.75×。
- 理由：省博的不可替代性是「方形回字盒 + 四边 23 m 悬挑 + 红黑像素化表皮 + 月光宝盒夜景」，不是把珠江新城按测绘做一遍。全 1:1 城市会把场景拉到 2 km+，稀释表皮精度、增加 draw calls/树/窗光。
- 代价：城市距离/体量不是实测；`axis` 视点的塔/图书馆/大剧院为示意。
- 缓解：保持轴线对齐、相对高度正确（塔 600、东塔 530、西塔 438.6、中信 391）、近景 1:1 锚定；页面标注「周边压缩，非测绘」。

### 取舍 2：内透深度 vs 外壳封闭性（推荐：浅内透，不做内部）

- 选择：洞口凹龛深度 0.6–2.4 m；玻璃窗背面用 emissive 面/暖/冷玻璃；大堂只做 3–9 m 的玻璃盒与室内发光面；**不做中庭/展厅内部**；中央天窗只做屋顶玻璃。
- 理由：A 范围是外观；真实内部会把工作量/性能/透明排序拉高，且容易露出空荡内部。省博的夜间魅力来自「黑盒 + 红色裂缝 + 暖色底座」的浅层透光，而不是可走进去的中庭。
- 代价：不能从洞口看到深层中庭/回廊；中央天窗下无内部；夜景深度是示意。
- 缓解：红内壁做真实凹深 + 少量暗部；玻璃窗分暖/冷/暗三类；大堂用发光面 + 点光；夜景 About 明确「内透为示意」。

## 10. 风险与决策

- **立面图案不像**：无公开立面图；用「大洞 + 竖槽 + L 形 + 顶部缺口 + 红内壁」的确定性族，手工调 hero 洞；接受"神似而非逐洞复刻"；页面标注估算。
- **红光过曝/塑料感**：ACES + 曝光 1.0–1.1；red emissive 1.6–2.0；暗部红 `#8e1418`；无 bloom；用对比而非亮度。
- **玻璃透明排序**：用不透明深色玻璃 + emissive 背面；不做大面积透明；必要时 `depthWrite:false` + renderOrder。
- **阴影 acne/漏光**：2048/1024 阴影 + bias/normalBias；薄洞口用环境暗部/顶点色补；夜间关阴影。
- **移动端性能**：先降城市块/树/格栅/东/北/南洞口；不降西门立面/盒体轮廓/中央天窗。
- **城市压缩被误读**：页面/标题/About 明确「周边压缩，非测绘」；塔距离 0.75×；不写真实距离。
- **事实口径**：44.5/44.8 并列；不写铜板；不写"只有四个切口"；照明单位未确认；不写具体开孔率。
- **接入残差**：城市通用返回当前落到 `chenjiaci`；记录为既有行为，不擅自改父页；主会话可另定中性落点。
- **命名**：只写广东省博物馆/广东省博物馆新馆/月光宝盒；不写广州博物馆/镇海楼。
- **版权**：所有纹理程序化；参考图只做观察；不下载版权贴图；字牌只写馆名，不画 LOGO。
